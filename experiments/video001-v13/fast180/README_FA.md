# مسیر آزمایشی V13 برای هدف واقعی سه دقیقه — بدون دستکاری V12 یا آرشیو خام

**وضعیت فعلی: ۳ دقیقه ثابت نشده است.** این پوشه فقط «کد آزمایشی» است. هیچ کدام از چهار مدل کامل دیداری/گفتاری V13 و تأیید انسانی روی این مسیر به‌شکل یک اجرای ۹۰دقیقه‌ای زیر ۱۸۰ ثانیه آزموده نشده‌اند.

## اندازه‌گیری واقعی قبلی، نه وعده
- فیلم سوم با مدت ۵۱۵۷٫۱۹۸۳۶۷ ثانیه و منبع SHA-256 `a2721fb01575f9ad4859f594e5c6fa6852e31dce353e31f70eed1a8edb3bbfbb`: آماده‌سازی از منبع در گزارش واقعی ۲۶۴٫۳۵ ثانیه؛ **به تنهایی بیشتر از سقف ۱۸۰ ثانیه**.
- [استخراج موازی CPU گفتار همان فیلم از آرشیو ۱۸ بخش](https://github.com/aminzare121-maker/amin-faraz/actions/runs/42534706203): حدود ۲۴۴ ثانیه از شروع تا ادغام؛ **این آزمون دریافت MP4 و OCR و تخته را شامل نمی‌شود**. این دو اجرا قابل جمع‌زدن به‌عنوان زمان واقعی یک اجرای مشترک نیستند.
- [آرشیو OCR و آماده‌سازی اولیه فیلم سوم](https://github.com/aminzare121-maker/amin-faraz/actions/runs/42426863832) از نظر OCR چت در مسیر CPU بخش‌هایی موفق و گفتار در همان اجرا شکست داشت. صحت معنایی مدرس هنوز مستقل تأیید نشده است.

## اصلاح واقعی اعمال‌شده
1. `batched_gpu_asr.py`: مسیر آزمایشی مدل `large-v3-turbo` روی CUDA با `BatchedInferencePipeline` و مدل بارگذاری‌شده برای چند قطعه در همان پردازش، تقسیم‌پذیر بین GPUها؛ بررسی هش و شمارهٔ تمام قطعات قبل و بعد از پردازش، منع overwrite متن خام، نگهداری **تمام** متن‌های برگشتی حتی پنجره‌های هم‌پوشان؛ **نتیجه این موتور معادل متن قبلی نیست و نیازمند ممیزی کیفیت مستقل است**.
2. `speed_acceptance.py`: کنترل شرط واقعی «از لحظه دریافت منبع تا ذخیره نهایی خروجی متنی» با زمان UTC، پوشش ۱۸ قطعه برای ۹۰ دقیقه، OCR چت، تبدیل متن تخته و توضیح تصویری، پرسش‌وپاسخ، نگهداری محتوا، کنترل منبع و اعتبارسنجی مستقل کیفیت؛ رد آرشیو ازقبل‌استخراج‌شده به‌عنوان معیار زمان کامل.
3. شرط ارتقای حالت سریع: **سه اجرای واقعی قابل‌مقایسه**، هر سه زیر ۱۸۰ ثانیه، بدون افت دقت؛ آزمون ساختاری یا خروجی مصنوعی نمی‌تواند شرط را برقرار کند.
4. آزمون‌های آفلاین بدون ویدیو، بدون GPU و بدون معامله؛ تغییرات فقط در این شاخه انجام شده‌اند.

## دستور اجرای نامزد GPU (پس از تهیه مجاز GPU و منابع خصوصی)
```bash
python batched_gpu_asr.py \
  --source-audio-root /private/extracted/full_audio \
  --out /private/v13_gpu_candidate \
  --video-sha256 <SHA256_OF_REGISTERED_ORIGINAL_VIDEO> \
  --gpu-index 0 --gpu-count 1 --batch-size 16
```
در صورت نبود CUDA **خطای واقعی** می‌دهد؛ CPU جایگزین مخفی ندارد. برنامه ورودی را تغییر نمی‌دهد و خروجی‌ها را در مسیر مستقل می‌نویسد. تنها ASR است و OCR/بینایی را کامل نمی‌کند.

برای صدور رسید سه‌دقیقه‌ای پس از ایجاد **سه سند واقعی با تمام فیلدهای صحیح**:
```bash
python speed_acceptance.py --receipts /private/three_verified_end_to_end_runs.json \
  --output /private/under_180_verdict.json
```
ساختن فایل نمونه یا تغییر اعداد برای قبولی ممنوع.
