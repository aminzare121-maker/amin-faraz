# منابع اصلی طراحی کابین امین، برگرفته از Library

**وضعیت:** مرجع طراحیِ مستقل، صرفاً پیش‌نمایش؛ نه نرم‌افزار اجرایی و نه نمایش داده واقعی. مرتبط با [Issue #16](https://github.com/aminzare121-maker/amin-faraz/issues/16).

## فایل واقعی منتقل‌شده
- [faraz_ui_concepts_original.html](faraz_ui_concepts_original.html) — **خود فایل اصلی تعاملی** از Library حساب مالک، نه بازسازی از روی توضیح. شامل طرح‌های ۱/۲/۳، پیش‌نمایش ویندوز/موبایل، صفحه‌های ناوبری و کد HTML/CSS/JS. سبک اولیه/منتخب برای کابین v2: **طرح ۱ معامله‌گر حرفه‌ای، سرمه‌ای تیره**.
- این فایل به‌صورت *نمونه طراحی آفلاین* قابل بازکردن است و هیچ دستور معاملاتی یا اتصال بروکر ندارد. داده‌های آن ساختگی‌اند و نباید به‌عنوان داده حساب نمایش داده شوند.
