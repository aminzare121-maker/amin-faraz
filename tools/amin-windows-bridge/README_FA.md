# پل امن امین بین ChatGPT و ویندوز — نسخه آزمایشی ۰٫۱

**وضعیت:** کد و تست‌ها آماده‌اند؛ اتصال زنده **تا زمانی که برنامه روی ویندوز اجرا و مجوز GitHub محلی داده نشده، برقرار نیست**. این برنامه کنترل کامل صفحه‌نمایش یا معادل همه قابلیت‌های Codex نیست؛ یک پل محدود برای انجام کارهای مفید و قابل بازبینی روی فایل‌های یک پوشهٔ مشخص است.

## کارهایی که همین نسخه واقعاً انجام می‌دهد

- از [Issue شماره ۳۸ مخزن خصوصی](https://github.com/aminzare121-maker/amin-faraz/issues/38) فرمان‌های ساختاریافتهٔ صاحب حساب را می‌خواند و نتیجه را همان‌جا برمی‌گرداند.
- **status**: وضعیت پل و فهرست توانایی‌ها؛ **list_files**: فهرست محدود فایل‌های یک پوشه؛ **file_hash**: کنترل SHA256 فایل کد؛ **syntax_check**: بررسی نحو پایتون بدون اجرای کد.
- **read_code**: مشاهده بخش محدودی از متن کد، فقط با تأیید روی همان لپ‌تاپ؛ **run_unittest**: اجرای آزمون Python و گزارش نتیجه، فقط با تأیید همان‌جا. اجرای تست یک عملیات واقعی و *sandbox نشده* است؛ تنها روی پوشه و کد مورداعتماد تأیید شود.
- روی همان مخزن **خصوصی** کار می‌کند. مسیرهای خارج از workspace، میان‌بر symbolic، فایل‌های CSV قیمت، فایل‌های مخفی/رمز، shell آزاد، نصب، ویرایش کد، MetaTrader و هر نوع معامله مسدودند.
- در نسخه حاضر هیچ فرمانی برای تایپ در ویندوز، کنترل موس، باز کردن برنامه، Git merge یا آپلود داده خام وجود ندارد. توسعهٔ این موارد فقط با درخواست و تأیید جدید است.

## راه‌اندازی یک‌باره به کمک کدکس ویندوز

۱. کدکس چهار فایل برنامه را از [Draft PR مربوط به Bridge](https://github.com/aminzare121-maker/amin-faraz/pulls) به یک پوشهٔ جدا (مثلاً `AminBridge`) روی ویندوز ۱۱ منتقل کند، **بدون تغییر موتور فراز، آرتین، جارویس یا تنظیمات ویندوز**. برای تست Python 3.10 یا جدیدتر کافی است و هیچ بسته جدیدی لازم نیست. کدکس خودش کد موجود را ممیزی و ۱۳ تست را دوباره اجرا کند.

۲. صاحب دستگاه یک پوشهٔ مشخص و کم‌خطر به‌عنوان *فضای مجاز* انتخاب کند، ترجیحاً نسخهٔ کپیِ پروژهٔ پژوهشی، نه کل `C:\` و نه پوشهٔ کاربران/اسناد شخصی.

۳. احراز هویت GitHub باید **روی خود ویندوز** انجام شود. برنامه اول از `AMIN_BRIDGE_GH_TOKEN` استفاده می‌کند، اگر نبود از `gh auth token` در صورت نصب قبلی، وگرنه در همان کنسول به‌صورت مخفی از کاربر GitHub Fine-grained PAT می‌خواهد. این توکن فقط برای مخزن `aminzare121-maker/amin-faraz` با مجوز **Issues: Read and Write** باشد، با تاریخ انقضا؛ **توکن را هرگز در ChatGPT، GitHub Issue، PR یا کد قرار ندهید**.

۴. برای نخستین بررسی **START_ONCE_WINDOWS.bat** را اجرا کنید و مسیر همان پوشه مجاز را وارد کنید. برنامه یک بار فرمان‌های جدید Issue38 را می‌خواند و پایان می‌یابد؛ در صورت نیاز برای مشاهده فرمان جدید دوباره اجرا شود.

۵. فقط پس از دیدن نتیجه موفق و تأیید مالک، می‌توان با **START_WATCH_WINDOWS.bat** برنامه را در یک پنجرهٔ باز نگه داشت. هر ۴۵ ثانیه فرمان‌های Issue38 بررسی می‌شوند و با بستن پنجره یا Ctrl+C متوقف می‌شود. برنامه در Startup ثبت نمی‌شود و سرویس دائم ایجاد نمی‌کند.

۶. نتیجه در GitHub با پیشوند `AMIN-WIN-RESULT-v1` ظاهر می‌شود؛ ChatGPT می‌تواند از همان اتصال GitHub نتیجه را بخواند، کد جدید را در شاخه جداگانه بنویسد و سپس درخواست **بررسی و آزمون** بدهد. نوشتن کد در repo به‌تنهایی فایل ویندوز را تغییر نمی‌دهد.

## ممنوعیت‌های مهم

هیچ بارگذاری raw کندل XAUUSD.st یا فایل حساب مجاز نیست. برای درخواست `read_code` به پنجرهٔ محلی اجازه لازم است و متن خوانده‌شده در Issue خصوصی ذخیره می‌شود؛ فایل حاوی رمز و اطلاعات شخصی را تأیید نکنید. `run_unittest` می‌تواند کد دلخواه موجود در تست‌ها را اجرا کند؛ برنامه ادعای sandbox یا محافظت کامل ندارد. هیچ سفارش مالی، معامله DEMO/REAL، اتصال MT5، نصب، Merge، ویرایش یا حذف فایل بدون طراحی و تأیید مستقل مجاز نیست.

## آزمون برنامه

از داخل پوشهٔ برنامه:

```powershell
py -3 -m unittest -v test_bridge_agent.py
```

۱۳ آزمون شامل رد کردن مسیر خارج، دسترسی به فایل حساس، فرمان ناشناس، حملهٔ تکرار، موافقت محلی و بازیابی نتیجهٔ ارسال‌نشده هستند. **قبولی تست‌ها اثبات اتصال زنده یا امنیت مطلق نیست**؛ برای مرحلهٔ نهایی، آزمایش رفت‌وبرگشت واقعی در Issue38 لازم است.

## پروتکل پیام

پیشوند پیام درخواست باید دقیقاً در ابتدای یک کامنت باشد:

```text
AMIN-WIN-REQ-v1
{"id":"test-connection-1","action":"status"}
```

درخواست‌های ممکن (همه داخل workspace):

```text
AMIN-WIN-REQ-v1
{"id":"check-lab-1","action":"syntax_check","path":"research/faraz-local-lab"}
```

```text
AMIN-WIN-REQ-v1
{"id":"test-lab-1","action":"run_unittest","path":"research/faraz-local-lab","pattern":"test_*.py"}
```

برای `read_code`/`run_unittest` تأیید محلی ضروری است. تنها کامنت‌های نویسندهٔ حساب تأییدشده `aminzare121-maker` معتبرند. شناسه کامنت‌های انجام‌شده در حالت محلی ثبت می‌شود تا پیام تکراری دوباره اجرا نشود.
