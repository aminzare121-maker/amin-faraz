# Offline adapter contracts

No live execution has occurred. These stdlib-only contracts import no MT5 SDK, initialize no session, launch no terminal, send/check no orders, and change no settings. The bridge host must not expose Python objects or caller-controlled consent booleans to remote requests.

`ReadOnlyMarketAdapter` accepts a trusted dependency-injected proxy for an already-attached session. The host must supply successful bridge-handshake and specific-session owner-consent assertions. Both default to false. Account metadata must be normalized by that trusted proxy to exact `mode=DEMO`, `broker=Eplanet`; exact symbol metadata must be `XAUUSD.st`. Guard checks precede market reads. Only closed M15 bars, position 1, count 1..100 are requested. Output discards all rows/metadata and exposes only ok, constant symbol, row count, fixed error code. This does not validate price quality or timestamp provenance.

The only SDK methods used are fixed direct calls to account_info, symbol_info and copy_rates_from_pos. No arbitrary method-name dispatch is available; request_api always rejects, even otherwise allowlisted names. Python object encapsulation is not a hostile-code sandbox: the trusted bridge host owns its proxy and transport routing. Fixed-code in-memory audit events never contain SDK exception text, account fields, rows or request method names. Host owns bounded persistence/rotation.

`RobotObserver` requires the exact owner-approved status path AND trusted-schema assertion. Unknown path means PATH_APPROVAL_REQUIRED and unknown status. It reads at most 4097 bytes and accepts only schema=1, status running/stopped, heartbeat_epoch; extra fields are rejected. A trusted recent heartbeat is necessary for both running and stopped; stale/future timestamps return unknown. File absence or invalid JSON returns fixed safe codes, no path/content/error details. Ordinary robot logs are deliberately not parsed: an owner-approved trusted status producer/schema is needed.

Lexical parent traversal and symlink/junction components are rejected. Symlink rejection is tested via deterministic policy mock, not creation of a real Windows symlink. Pre-open path checks have a local filesystem race: a hostile writer could replace a path between check and open. Therefore live wiring requires the bridge host to enforce an approved immutable location/ACL or a Windows no-follow, verified-handle reader. No production filesystem security claim is made. No robot binary path was provided: version/hash of actual robot remains blocked, and no backup or configuration read was attempted.

Synthetic example: proxy DEMO/Eplanet/XAUUSD.st and 100 synthetic rows returns `{ "ok": true, "symbol": "XAUUSD.st", "count": 100, "error": "OK" }`; synthetic trusted running status at epoch1000 observed at1010 returns `{ "ok": true, "status": "running", "error": "OK" }`. These are not live observations.

Verification: Python3.12.14 from the existing project virtualenv, stdlib unittest, 25 tests passed, 0 failures/errors/skips. Latest actual output is test-results.txt. Tests cover denied consent, REAL, wrong broker/symbol/count, method dispatch, exception/audit privacy, approved running/stopped schema, stale/future, oversized content, unexpected/private fields, traversal, symlink policy mock, actual synthetic hardlinks, reparse-attribute mock, missing/failed audit before reads, bounded local JSONL, and empty/malformed rows. No SDK import, network, account access, process control, other-project changes or GitHub mutation.

Authorized inspections now require a trusted audit sink. JsonlAuditSink writes only fixed-code JSONL to an explicitly host-approved destination; file selection is never taken from GitHub/request input. It enforces a maximum 65536-byte file, rejects hardlinks/reparse points, flushes/fsyncs, and fails closed when unavailable/full. It does not create directories, rotate logs, or log arbitrary payloads. The host must serialize writers and secure paths; the local hostile-writer race caveat also applies to this sink. Missing or failed logging before account/symbol/market calls blocks that call. In-memory events are capped at 256.

Trusted proxy rows must be a list/tuple of exact dictionaries with time/open/high/low/close, integer nonnegative M15-grid time, finite positive numeric prices and valid OHLC ordering. Empty history returns HISTORY_UNAVAILABLE, never connected-history success. No actual SDK binding/normalizer is implemented: numpy structured rates and account enums require a separately reviewed host binding. These minimal checks establish shape only; continuity, origin, historical clock alignment and actual market freshness are not established. Row values remain private and are discarded from adapter output.

Remaining live prerequisites: root completes bridge audit/handshake; owner authorizes the particular attached session; trusted proxy normalizer is reviewed; owner supplies exact robot status/binary approvals; host enforces file handle/path security. No live success is claimed.
