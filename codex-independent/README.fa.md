# نسخهٔ مستقل دریافت و آرشیو کندل آرتین

این پروژه ابزار دریافت فقط‌خواندنی و ممیزی داده است؛ موتور معاملاتی نهایی یا تأیید معنایی ۲۵ جلسه نیست. هیچ API ارسال سفارش ندارد. شاخهٔ مستقل `codex-artin-mt5-independent` است؛ نسخه‌های ChatGPT و main تغییر داده نمی‌شوند.

## اجزا

- `mql5/ArtinIndependentCapture.mq5`: اسکریپت یک‌بارهٔ DEMO مخصوص ePlanet، دریافت کندل‌های بستهٔ طلا/M15، خروجی فایل مستقل در Common Files. EX5 باید با MetaEditor واقعی ساخته شود؛ CI این کار را شبیه‌سازی نمی‌کند.
- `python/observe_demo.py`: یک چرخهٔ SDK فقط‌خواندنی در ترمینال موجود، با کنترل DEMO، سرور، شرکت و مسیر دادهٔ مورد انتظار؛ تاریخچهٔ بسته را به آرشیو می‌دهد. `--terminal` و `--expected-data` باید مسیرهای واقعیِ ازقبل تأییدشده باشند. اطلاعات حساب/رمز لازم نیست و نباید در خط فرمان قرار گیرد.
- `python/import_mql_capture.py`: خروجی واقعی EX5 را فقط با رسیدِ هش‌دار و تطبیق باینری/سورس وارد آرشیو می‌کند؛ خود آن به MT5 وصل نمی‌شود.
- `python/candle_archive.py`: کنترل OHLC، زمان اصلی، تکرار/تعارض، بازیابی مرحله‌ای، زنجیرهٔ هش، checkpoint و anchor و قفل سیستم‌عامل. فاصلهٔ زمانی بدون شاهد سشن/تاریخچه، `GAP_UNRESOLVED` است؛ کندل مصنوعی ساخته نمی‌شود.
- `python/verify_archive.py`: ممیزی مستقل زنجیره؛ `--pin-file` یک head نگه‌داشته‌شدهٔ مستقل را می‌پذیرد. بازنویسی هماهنگ تمام داده‌ها و تمام شاهدهای محلی بدون pin خارجی قابل تضمین نیست.
- `python/path_registry.py`: فقط ۱۳ جایگاه ساختاریِ بدون نگاشت نهایی؛ همه نیازمند شاهد و مسدودند. هیچ فرمول یا نام قانون از خودمان برای پرکردن آن‌ها ساخته نشده است.

## آزمون

از ریشهٔ مخزن: `python codex-independent/python/validate_project.py` آزمون‌های عادی و `-O` و benchmark ساختگیِ آرشیو را اجرا می‌کند. این فرمان به MT5 وصل نمی‌شود و فیلمی استخراج نمی‌کند. برای ممیزی زنجیره: `python codex-independent/python/verify_archive.py --root PRIVATE_ARCHIVE`.

برای دریافت واقعی، Python دارای بستهٔ نصب‌شدهٔ MetaTrader5 لازم است. `observe_demo.py --archive PRIVATE_ARCHIVE --snapshot NEW_PRIVATE_JSON --report NEW_REPORT_JSON --terminal VERIFIED_EXE --expected-data VERIFIED_DATA_PATH` فقط یک چرخه انجام می‌دهد. ابتدا بازبودن همان ترمینال DEMO کنترل شود؛ اجرای پیوسته یا راه‌اندازی خودکار پس از reboot در این نسخه تنظیم نشده است. SDK initialization ممکن است در صورت بسته‌بودن ترمینال آن را باز کند؛ برای این آزمون، ترمینال موجود قبلاً شناسایی شده بود. اتصال SDK با اجرای خود اسکریپت EX5 یکسان نیست؛ گزارش هرکدام جداست.

آرشیو و snapshotهای خام در `runtime/` خصوصی و خارج از Git هستند. رسیدهای غیرحساس و هش head برای بازبینی در `reports/` قرار می‌گیرند. هیچ فایل V2..V7، EA موجود، پورت عمومی، سیاست امنیتی یا تنظیم معاملات تغییر داده نمی‌شود.
