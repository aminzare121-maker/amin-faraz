# هوش امین — پل مستقیم خصوصی بین گوشی/ویندوز، GitHub و عامل ChatGPT

## مسیر عملی
مخزن کد `aminzare121-maker/amin-faraz` عمومی باقی می‌ماند. هر کاربر برای ارتباط اختصاصی خود به **یک مخزن خصوصی GitHub تحت کنترل حساب خودش** نیاز دارد. هیچ توکن/مکالمه‌ای در مخزن عمومی ذخیره نمی‌شود.

- **اندروید:** بخش «پل مستقیم GitHub خصوصی» در نسخه تازه اپ `com.amin.support.mobile` (کنار حالت قبلی موتور HTTPS، نه جایگزین آن). نام `owner/repo` و توکن محدود GitHub با مجوز Issues و Metadata را وارد می‌کند. اپ با Android Keystore کلید را رمزگذاری می‌کند، با GitHub API مخزن خصوصی را تأیید می‌کند و فقط بعد از تأیید کاربر Issue ایجاد می‌کند.
- **ویندوز:** اسکریپت `amin-ai-support/direct_github_relay.py` با Python استاندارد و همان API. در PowerShell ویندوز توکن باید به‌عنوان متغیر محیطی **فقط در همان نشست** تنظیم شود؛ هرگز به فایل عمومی/لاگ یا مخزن push نشود.
- **ChatGPT:** کاربر باید در حساب ChatGPT خودش GitHub را متصل کند؛ برنامه تلفن نمی‌تواند توکن نشست ChatGPT را دریافت کند و GitHub قادر نیست به‌طور مستقیم یک چت خصوصی را بیدار کند. برای صاحب این مخزن می‌توان «وظیفه زمان‌بندی‌شده ChatGPT» ایجاد کرد تا درخواست‌های معتبر در مخزن خصوصی را با اتصال GitHub بخواند، پاسخ کند و پاسخ را در همان Issue خصوصی ثبت نماید. دوره بررسی این وظیفه حداقل یک ساعت است، **نه ارتباط لحظه‌ای**؛ تأخیر شبکه یا محدودیت سهمیه ممکن است بیشتر باشد.
- **بازگشت پاسخ:** برنامه آخرین Issue را با توکن همان حساب می‌خواند و تنها نظر با قالب `AMIN_CHAT_REPLY_V1` از مالک مخزن و با `request_id` یکسان را نشان می‌دهد. این یک پاسخ است، نه اثبات نصب/اجرای کد.
- **یادگیری:** تغییر خودکار مدل AI انجام نمی‌شود. راه‌حل‌های تأییدشده در موتور قبلی می‌توانند به دانش جداگانه پروژه اضافه شوند؛ ادعای بازآموزی بدون نظارت ممنوع است.

## قالب درخواست (Issue در مخزن خصوصی)
```text
AMIN_CHAT_BRIDGE_V1
{"request_id":"32-hex","project":"support","device":"android|windows",
 "question":"متن فارسی درخواست","consent":true,
 "result_required":"AMIN_CHAT_REPLY_V1"}
```
عنوان عمومی نیست؛ Issue شامل پرسش واقعی است و برای **همه همکاران مجاز مخزن خصوصی** قابل مشاهده خواهد بود. محتوای حساس یا دسترسی‌های تولیدی نباید بدون نیاز به اشتراک گذاشته شوند. جداکردن مخزن هر کاربر الزامی است.

## قالب پاسخ (GitHub Issue comment از مالک مخزن)
```text
AMIN_CHAT_REPLY_V1
{"request_id":"32-hex","status":"answered",
 "answer":"پاسخ بررسی‌شده به فارسی؛ اگر اجرا نشده صریحاً مشخص شود"}
```
درخواست‌های فاقد پروتکل، از فرستنده غیرمجاز یا شامل دستور مخرب نباید خودکار اجرا شوند. GitHub Issues محل اجرای کد نیست؛ اصلاح نرم‌افزار فقط در branch/PR مجزا، با آزمون و مجوز لازم انجام شود.

## راه‌اندازی ویندوز
```powershell
# در همان نشست PowerShell، توکن محدود فقط از ورودی امن دریافت شود:
$env:AMIN_PRIVATE_GITHUB_TOKEN = "<private-repo-scoped-token>"
python amin-ai-support/direct_github_relay.py --repo OWNER/PRIVATE_REPO verify
python amin-ai-support/direct_github_relay.py --repo OWNER/PRIVATE_REPO submit --project support --message "سلام، این یک درخواست است"
python amin-ai-support/direct_github_relay.py --repo OWNER/PRIVATE_REPO list
python amin-ai-support/direct_github_relay.py --repo OWNER/PRIVATE_REPO status --issue 1 --id 0123456789abcdef0123456789abcdef
Remove-Item Env:\AMIN_PRIVATE_GITHUB_TOKEN
```
این دستورات فقط نمونه نحو هستند و فاقد توکن یا Issue واقعی‌اند. هنگام انجام اتصال کاربر باید توکن واقعی خودش را وارد کند. برای سهولت می‌توان پنجره مدیریت ورودی امن جداگانه ساخت.

## شرایط واقعی استفاده
- گوشی به `api.github.com` دسترسی شبکه داشته باشد. در اینترنت محدود ایران این مورد هنوز روی دستگاه مقصد آزمایش نشده است.
- کاربران باید حساب GitHub، مخزن خصوصی، مجوز محدود Issues و اتصال اختصاصی GitHub در ChatGPT خودشان داشته باشند. هیچ اشتراک پولی GitHub الزام نشده و توکن مشترک مالک به مشتریان داده نمی‌شود.
- دسترسی به چت شخصی کاربر از بیرون به‌صورت خودکار برقرار نمی‌شود. هر کاربر باید اتصال و گردش‌کار شخصی خودش را فعال کند؛ وظیفه زمان‌بندی‌شده ChatGPT تنها روش مشروط موجود در این مرحله است.
- درخواست‌ها، پاسخ‌ها و سوابق GitHub خصوصی‌اند، اما محرمانگی سرتاسری رمزنگاری‌شده بین مشتری و مدل تضمین نشده است. به GitHub و سرویس پاسخ‌دهنده اعتماد لازم است.
- نسخه قبلی برنامه جواب و موتور محلی بدون تغییر در کارکرد اصلی باقی می‌مانند.
- تست واحد و ساخت APK به تنهایی قبولی روی Galaxy M62 نیست. تست با اتصال واقعی و اجازه نصب دستگاه لازم است.

## حافظه راه‌حل‌های تأییدشده
پس از دریافت پاسخ در گوشی یا ویندوز، مالک می‌تواند با دکمه «تأیید پاسخ صحیح برای حافظه پروژه» یا فرمان `approve` آن را **پس از کنترل واقعی** تأیید کند. این دکمه فقط درخواستی را می‌پذیرد که پاسخ معتبر همان `request_id` از صاحب مخزن دریافت کرده باشد. علامت خصوصی زیر، بدون تکرار متن حساس، در همان Issue ثبت می‌شود:

```text
AMIN_LESSON_APPROVED_V1
{"request_id":"32-hex","project":"support","approved":true}
```

عامل ChatGPT می‌تواند در نوبت‌های بعدی و صرفاً برای `project` برابر، پاسخ‌های قبلی دارای این تأیید را به‌عنوان **راهنمای مورد پذیرش مالک** مرور کند. این «حافظه قابل بازیابی» است؛ **بازآموزی وزن‌های مدل یا اثبات صحت فنی راه‌حل نیست**. رد/لغو درس، اندازه‌گیری کیفیت قبل/بعد و همگام‌سازی واقعی با موتور SQLite همچنان باقی هستند.

در ویندوز از منوی شماره ۴ برنامه PowerShell یا دستور زیر استفاده کن:
```powershell
python amin-ai-support/direct_github_relay.py --repo OWNER/PRIVATE_REPO approve --project support --issue 1 --id 0123456789abcdef0123456789abcdef
```

### راه‌اندازی ساده‌تر در ویندوز
`amin-ai-support/windows/Start-AminPrivateGitHub.ps1` پنجره متنی فارسی برای بررسی اتصال، ارسال، فهرست، دریافت پاسخ و تأیید راه‌حل فراهم می‌کند. توکن در فایل ذخیره نمی‌شود و هنگام خروج از متغیر محیطی این نشست پاک می‌شود. این ابزار به نصب Python نیاز دارد و روی Windows 11 مالک **هنوز به شکل حضوری آزمایش نشده است**.

### بررسی پاسخ خودکار روی گوشی
در نسخه جدید، وقتی اپ در پیش‌زمینه باشد و یک Issue معتبر ثبت شده باشد، وضعیت پاسخ تقریباً هر دو دقیقه بررسی می‌شود. این کار در پس‌زمینه، هنگام قفل بودن گوشی یا قطع اتصال تضمین‌شده نیست و دسترسی GitHub با اینترنت مقصد باید آزمون شود.
