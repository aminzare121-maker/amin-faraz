## رفتار عملی پیاده‌شده
این اپ، وقتی در پیش‌زمینه است، هر دو دقیقه از API عمومی GitHub پرونده‌های باز با عنوان «برنامه جواب | ...» و بدنه معتبر `JAVAB_TASK_V1` را می‌خواند و فقط پرونده‌هایی را معتبر می‌داند که نویسنده‌شان `aminzare121-maker` و شناسه Task در بدنه برابر شماره Issue باشد. هیچ رمز یا کلید GitHub لازم ندارد. اگر حداقل یک کار باز وجود داشته باشد، `FLAG_KEEP_SCREEN_ON` را روی **پنجره خودش** اعمال می‌کند. در صورت نبود کار یا بستن پرونده آخر، از پیش‌زمینه خارج‌شدن یا خطای دسترسی، پرچم آزاد می‌شود.

- تغییرات GitHub حداکثر پس از اجرای بعدی بررسی (معمولاً حدود دو دقیقه) به اپ می‌رسند؛ رویداد آنی Push پیاده نشده است.
- وضعیت «Issue باز» فقط ادامه داشتن کار ثبت‌شده است؛ نشانه اجرای واقعی پردازشگر در همان لحظه نیست.
- روی صفحه **اپ جداگانه ChatGPT** اعمال `FLAG_KEEP_SCREEN_ON` ممکن نیست. اپ باید روی صفحه گوشی جلو باشد.
- قفل دستی/دکمه پاور، روشن‌شدن قطعی پس از خاموشی و کنترل از راه دور نمایشگر **پیاده‌سازی نشده** و OS اجازه نامحدود نمی‌دهد.
- اتصال به GitHub تحت اینترنت ملی ممکن است در دسترس نباشد؛ این مورد روی گوشی ایران آزمایش نشده است.
- نسخه `debug` برای آزمون داخلی است، نه انتشار تجاری. امضای debug ممکن است در ساخت بعدی تغییر کند؛ نصب به‌روزرسانی بعدی ممکن است به حذف نسخه قبلی نیاز داشته باشد.

## نصب دستی روی گوشی Android
1. APK را از خروجی GitHub Actions یا فایل تحویل داده‌شده دریافت کنید.
2. فایل `app-debug.apk` را باز کنید و اگر Android درخواست کرد، برای برنامه‌ای که فایل را باز می‌کند گزینه **اجازه نصب از این منبع** را فعال کنید.
3. «برنامه جواب امین» را باز نگه دارید. اپ فوراً GitHub را بررسی می‌کند و فهرست کارهای باز را نشان می‌دهد.
4. برای بررسی مجدد بدون انتظار، دکمه «بررسی مجدد پرونده‌ها» را لمس کنید.
5. توقف واقعی باید در «برنامه جواب» ثبت شود و Issue مربوط بسته شود؛ پس از بررسی جدید، نمایشگر به حالت عادی بازمی‌گردد.

**مهم:** این نصب روی دستگاه کاربر توسط ChatGPT انجام نشده است؛ در این مرحله فقط APK واقعی ساخته و دریافت شده است. آزمون دستگاه، بررسی رفتار پس از قفل، مصرف باتری و امنیت نهایی باقی مانده‌اند.

## مسیر توسعه برای خواسته نهایی مالک
برای اثر روی صفحه ChatGPT هنگام فعال بودن آن، به قابلیت مجاز و نصب‌شده‌ای در همان Activity یا یک روش تاییدشده اندروید نیاز است. اپ مستقل این مجوز را به اپ ChatGPT منتقل نمی‌کند. هیچ ادعای رفع این محدودیت وجود ندارد و برنامه جواب تا قبولی عملی نباید کامل اعلام شود.
