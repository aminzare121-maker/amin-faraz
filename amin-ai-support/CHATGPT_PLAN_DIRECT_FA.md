# اتصال مستقیم هوش امین به طرح ChatGPT — بدون Codex، Work یا API پولی

## کشف مسیر رسمی جدید (نوامبر ۲۰۲۶)

طبق [مستندات رسمی Sign in with ChatGPT](https://developers.openai.com/siwc/quickstart)، **نرم‌افزار متن‌باز روی رایانهٔ خود کاربر** می‌تواند با رضایت او، از سهمیهٔ ChatGPT Plus/Pro برای درخواست‌های مجاز هوش مصنوعی استفاده کند. نیازی به API Key جداگانه یا پرداخت مصرف API نیست. این روش از مسیر OAuth رسمی `auth.openai.com` و سپس `https://api.openai.com/v1/responses` با **توکن اختصاصی مجاز اشتراک** استفاده می‌کند. این به معنای خرید API نیست و به Codex یا Work احتیاج ندارد.

**دقت:** این دسترسی مدل به **همین رشتهٔ مکالمهٔ ChatGPT، حافظه و ابزارهای متصل به ChatGPT** دسترسی نمی‌دهد. مدل را می‌توان با ابزارهای کنترل‌شدهٔ GitHub در خود هوش امین به عامل اجرایی تبدیل کرد، ولی تا آن ابزارها ساخته و تست نشوند، فقط پاسخ هوشمند است نه «ساخت واقعی هر برنامه».

## کد افزوده‌شده

`chatgpt_plan_direct.py`:
- ثبت‌نام OAuth پویا با `dynamic_agent_client` و شناسه ثابت نصب (UUID)
- احراز هویت مرورگر رسمی با PKCE S256، state و nonce تصادفی و callback صرفاً در `127.0.0.1`
- بررسی امضای ID Token با JWKS رسمی OpenAI، issuer، audience و nonce؛ تطبیق هویت حساب قبلی
- عدم ذخیره کلیدهای OAuth در مخزن عمومی یا فایل بدون رمز؛ ذخیره در Credential Vault سیستم‌عامل از طریق `keyring`
- تمدید توکن با توجه به expiry و محدودیت `earliest_refresh_at`
- نمایش مدل‌های مجاز حساب و درخواست Responses با `store:false` و `stream:true` و انتظار واقعی تا رویداد `response.completed`
- قطع کامل مسیر در نبود تأیید اشتراک، شبکه، سهمیه یا احراز هویت؛ **هیچ جایگزین API پولی** فعال نیست

`live_bridge.py` با `AMIN_SIWC_ENABLE=1` پاسخ‌های `ask` مالک را مستقیماً از این مسیر دریافت می‌کند؛ نه از Codex یا ChatGPT Work. هویت توکن `AMIN_LIVE_OWNER_TOKEN_ID` الزامی است. درخواست کاربران دیگر از سهمیه مالک پردازش **نمی‌شود**؛ هر مشتری برای استفاده از طرح ChatGPT باید با حساب خودش وارد شود.

## نصب روی لپ‌تاپ خودتان، بدون پرداخت جدید

در پوشه `amin-ai-support` روی ویندوز با Python:

```powershell
python -m pip install -r requirements-siwc.txt
python chatgpt_plan_direct.py login
python chatgpt_plan_direct.py status
python chatgpt_plan_direct.py models
"سلام. فقط بگو چه مدل هوشی هستی." | python chatgpt_plan_direct.py ask
```

در مرحله `login` باید **خودتان** وارد حساب ChatGPT شده و اجازه `chatgpt.tokens.use.direct` را بدهید. از هیچ‌کس رمز حساب، کوکی مرورگر یا API Key نخواهید. اگر اینترنت اجازه رسیدن به `auth.openai.com` و `api.openai.com` را نمی‌دهد، این اتصال کار نمی‌کند؛ DNS یا GitHub به‌تنهایی مشکل دسترسی را حل نمی‌کند.

وقتی آزمون آخر یک پاسخ واقعی با `model_used:true` و `source: SIWC ChatGPT plan` برگرداند، می‌توان موتور WSS را **برای کلید مالک** با متغیر `AMIN_SIWC_ENABLE=1` راه انداخت. مثل قبل برای موبایل از بیرون، کامپیوتر باید روشن و WSS امن با گواهی معتبر و مسیر شبکه قابل‌دسترس باشد.

## محدودیت‌های مهم و شرط کار اقتصادی

این روش برای **متن‌باز/استقرار روی رایانهٔ خود کاربر** مستند شده است. برای ارائهٔ تجاریِ میزبانی‌شده از راه دور یا فروش دسترسی اشتراکی به طرح ChatGPT، طبق مستندات رسمی باید مسیر مربوط به کسب‌وکار با OpenAI بررسی شود. **نمی‌توانید سهمیهٔ Plus خود را به کاربران دیگر بفروشید یا بین آنها تقسیم کنید.** هر کاربر فقط از حساب واجدشرایط خودش و با اجازهٔ مستقل استفاده می‌کند.

مدل با سهمیهٔ اشتراک محدود است، نه تضمین نامحدود یا قابل‌استفاده روی هر شبکه. فعلاً این اجرای نمونه یک پروژهٔ محلی است و هیچ پرداختی آغاز نمی‌کند. **آزمون روی Galaxy M62، ورود واقعی به حساب، دریافت پاسخ واقعی، انتشار/استقرار عمومی و انجام خودکار کدنویسی GitHub هنوز تأیید نشده‌اند.**

برای ابزارهای اجرایی GitHub باید جداگانه ابزارهای `read, create_branch, edit, create_pr, inspect_ci` را در عامل خودمان بسازیم؛ اجرای خودکار با احتیاط و فقط در مخزن و محدودهٔ مجاز کاربر. SIWC برای Responses امکان function/custom tools دارد، ولی hosted MCP/Code Interpreter و برخی ابزارهای داخلی ChatGPT در این مسیر پشتیبانی نمی‌شوند. این یک تفاوت واقعی با ابزارهای من در همین مکالمه است.

## معیار قبولی قبل از اعلام موفقیت

۱. کاربر روی ویندوز login انجام دهد و اجازهٔ سهمیه را تأیید کند؛ مدل از `models` واقعی انتخاب شود و `ask` پاسخ معتبر `response.completed` بدهد.

۲. گوشی با کلید اختصاصی و WSS به ویندوز وصل شود؛ سؤال به همین مدل برسد و با شناسهٔ درست به گوشی برگردد. ارسال‌های هم‌زمان به هم نریزند.

۳. در آزمون مستقل، مدل با ابزارهای GitHub **واقعاً** کد تغییر دهد، PR جداگانه بسازد، CI آن بررسی شود و خروجی به محیط انتخابی منتقل شود. تا وقتی آزمون سوم انجام نشده، دسترسی ChatGPT به معنی ساخت خودکار برنامه نیست.
