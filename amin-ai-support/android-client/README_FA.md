# هوش پشتیبان امین — کلاینت مستقل اندروید

## هدف

«هوش پشتیبان امین» باید **روی ویندوز و گوشی اندروید** به دانش و تنظیمات مشترک دسترسی داشته باشد و به نرم‌افزارهای متعدد با مدیر جداگانه خدمات بدهد؛ نه فقط پروژه‌های شخصی امین. این پوشه اپ بومی اندروید را برای همان API مرکزی `amin-ai-support/amin_support.py` فراهم می‌کند.

**این اپ با «برنامه جواب امین» که قبلاً نصب شده فرق دارد:** شناسه برنامه جدید `com.amin.support.mobile` است. نصب آن اپ قبلی `com.amin.javab.companion` را حذف نمی‌کند. اپ جدید گفت‌وگوی پشتیبانی است؛ اپ قبلی وضعیت برنامه جواب و روشن‌ماندن پنجره خود را کنترل می‌کند.

## قابلیت‌های موجود در کد

- نمایش فارسی و ورود سؤال فارسی در گوشی
- ثبت نشانی HTTPS موتور مشترک و کلید دسترسی محدود به یک نرم‌افزار
- رمزگذاری کلید در Android Keystore با AES-GCM و غیرفعال‌بودن پشتیبان‌گیری اپ
- دریافت فهرست نرم‌افزارهایی که کلید مشتری به آن‌ها اجازه دسترسی می‌دهد (`GET /api/projects`)
- پرسش از نرم‌افزار انتخاب‌شده (`POST /api/chat`) و نمایش پاسخ، مسیر منابع، وضعیت استفاده از مدل و نیاز به بررسی انسانی
- جلوگیری از تغییر مقصد ناخواسته کلید: تغییر نشانی سرور بدون کلید تازه ممنوع است
- ممانعت از HTTP، تغییر مسیر شبکه و نشانی نامعتبر؛ اعتبارسنجی عادی گواهی TLS اندروید فعال است و دور زده نمی‌شود
- بدون اشتراک یا API پولی در گوشی؛ `external_model_consent=false` صریحاً ارسال می‌شود
- بدون ذخیره دائمی مکالمه در گوشی؛ دکمه پاک‌کردن کلید و اتصال وجود دارد

## معماری و شرط اجرا

```
گوشی اندروید                  موتور مشترک روی ویندوز یا سرور مالک
┌───────────────────────┐    HTTPS معتبر    ┌─────────────────────────┐
│ اپ «هوش پشتیبان امین» │ ────────────────> │ /api/projects           │
│ شناسه نرم‌افزار/کلید │ ────────────────> │ /api/chat               │
│ پرسش و پاسخ فارسی   │ <──────────────── │ دانش SQLite + مدل محلی │
└───────────────────────┘                    └─────────────────────────┘
```

دانش پروژه‌ها، درس‌های تأییدشده، محدودیت‌های سهمیه مشتری و سیاست‌های مدیریت روی موتور مرکزی ذخیره می‌شوند. اگر موبایل و ویندوز به همان سرور متصل باشند، از **همان وضعیت مرکزی** استفاده می‌کنند؛ داده‌های گفتگو هنوز به صورت حساب‌محور بین دستگاه‌ها همگام نمی‌شوند.

به دلیل امنیت، **اپ فقط HTTPS با گواهی معتبر** را قبول می‌کند. نشانی `http://127.0.0.1:8765` روی ویندوز، از گوشی آدرس همان گوشی خواهد بود و کار نمی‌کند. برای دسترسی واقعی باید یک آدرس HTTPS قابل‌دسترسی از گوشی به موتور ویندوز/سرور وجود داشته باشد؛ این پل شبکه هنوز راه‌اندازی و روی اینترنت ملی ایران آزمایش نشده است. نیازی به خرید سرویس جدید در این مرحله نیست، اما دسترسی اینترنتی پایدار و امن برای کاربران بیرون از شبکه محلی هنوز حل نشده است.

## وضعیت صادقانه

- سورس اندروید و گردش‌کار رایگان GitHub برای ساخت APK نوشته شده‌اند.
- **وجود APK قابل نصب:** تنها پس از قبولی GitHub Actions این شاخه و دریافت artifact قابل تأیید است.
- **آزمون روی گوشی واقعی:** انجام نشده.
- **آزمون اتصال HTTPS به موتور فعال روی ویندوز:** انجام نشده.
- **مدل زبانی مستقل روی سخت‌افزار گوشی و حالت آفلاین:** هنوز پیاده‌سازی نشده. این نسخه یک کلاینت به موتور مشترک است؛ نمایش جواب مستند در حالت سقوط مدل، جایگزین اجرای هوش روی گوشی نیست.
- **مجوز تجاری، سرعت و پذیرش مدل:** همچنان نیازمند آزمون عملی روی مسائل مشتریان است.
- **اپ قبلی برنامه جواب:** تغییر داده نشده و باید همچنان کار کند.
- **دریافت پول از مشتریان:** از سیاست و اعتباردهی موتور مرکزی پیروی می‌کند؛ درگاه واقعی هنوز وصل نیست.

این نسخه هیچ مدل، سرور یا اشتراک پولی دانلود یا خریداری نمی‌کند. دانلود APK از artifact GitHub ممکن است برای کاربران اینترنت محدود ایران نیازمند مسیر انتقال فایل قابل‌دسترسی باشد.


## الحاقیه درخواست مالک: کانال دوطرفه خصوصی و ارجاع به هوش مرکزی (نسخه درحال آزمون)

در شاخه `feature/amin-ai-handoff-mobile-windows-20261122`، دکمه ارسال درخواست با رضایت و دکمه پیگیری پاسخ به اپ اضافه شده است. اگر موتور در پاسخ `needs_human=true` اعلام کند، کاربر می‌تواند گزینه ارجاع خودکار (خاموش به‌صورت پیش‌فرض) را فعال کند. نتیجه فقط با همان کلید دسترسی نرم‌افزار قابل دریافت است و شناسه آخرین درخواست فقط در تنظیمات خصوصی همین برنامه نگهداری می‌شود.

**مهم:** این مسیر مستقیماً به چت خصوصی شخصی یا اجرای Codex وصل نیست. سرور درخواست را در SQLite خصوصی ثبت می‌کند و فقط به مخزن خصوصی GitHub با تأیید `private=true` اعلان بی‌محتوا می‌فرستد؛ مخزن عمومی هیچ داده شخصی یا شناسه درخواست دریافت نمی‌کند. پاسخ‌گویی از سمت عامل مجاز نیاز به پیاده‌سازی/اجرا و تأیید جداگانه دارد. برای هر مشتری کلید مستقل ضروری است. ساخت APK این شاخه، آزمون واقعی گوشی و آزمون اتصال هنوز باید با شواهد جدا تأیید شوند؛ نسخه debug قبلی هنوز این دکمه‌ها را ندارد.
