# هوش امین — گفت‌وگوی فارسی سبک آنلاین و اجرای رویدادمحور GitHub

## تصمیم مالک

- مدل‌های بزرگ تشخیص گفتار یا تولید صدای آفلاین **از این نسخه حذف شدند**؛ هیچ فایل `.onnx` / `.gguf` یا موتور سنگین داخل APK یا لپ‌تاپ نصب نمی‌شود.
- «شنیدن فارسی» با سرویس گفتار نصب‌شدهٔ Android انجام می‌شود. بسته به تنظیمات گوشی، این سرویس ممکن است برای شناسایی گفتار به اینترنت متصل شود. «پخش فارسی» با Android TextToSpeech و بهترین صدای `fa` قابل‌دسترسی، ترجیحاً صدای باکیفیت شبکه، اجرا می‌شود. کیفیت صدای ChatGPT، سرعت پاسخ و عملکرد فارسی هر سرویس *بدون آزمون شنیداری گوشی تضمین نمی‌شود*.
- دکمهٔ **«شروع مکالمهٔ پیوستهٔ فارسی»** نیازمند مجوز میکروفون، رضایت برای ارسال متنِ تشخیص داده‌شده، و وجود کانال مجاز WSS یا مخزن خصوصی GitHub است. بدون فشار دکمهٔ میکروفون در هر نوبت، بعد از پاسخ خوانده‌شده نوبت بعدی را آغاز می‌کند؛ در هنگام پخش صحبت خودکار گوش نمی‌دهد تا صدای خود را دوباره ارسال نکند. کاربر می‌تواند از دکمهٔ «قطع صدای پاسخ و شنیدن دستور جدید» برای قطع صحبت استفاده کند.
- برنامه وقتی به پس‌زمینه می‌رود میکروفون را خاموش می‌کند. **فعال‌شدن خودکار میکروفون روی صفحهٔ قفل یا بعد از خاموش‌شدن صفحه، در این مرحله وجود ندارد.**

## موتور GitHub

کد موتور هوش امین در مخزن `aminzare121-maker/amin-faraz` قرار دارد. اجرای رویدادمحور «پاسخ از دانش مستندات» در مخزن **خصوصی** `aminzare121-maker/amin-mt5-review` با `.github/workflows/amin-private-on-demand.yml` فعال می‌شود:

1. گوشی از طریق GitHub REST API، Issue خصوصی با قالب `AMIN_CHAT_BRIDGE_V1` می‌سازد؛ موضوع و شناسهٔ هر درخواست مستقل‌اند.
2. رویداد `issues.opened` در GitHub Actions، **به شرط اعتبارسنجی مالک، مخزن خصوصی و رضایت**، `instant_issue_worker.py` را روی ماشین موقت GitHub اجرا می‌کند. هیچ سرور یا مدل بزرگ محلی روی گوشی یا ویندوز برای این مسیر لازم نیست.
3. خروجیِ دارای شواهد به‌صورت `AMIN_CHAT_REPLY_V1` در همان Issue خصوصی ثبت می‌شود و برنامه آن را بدون اختلاط با شناسهٔ درخواست دیگر می‌گیرد.
4. این کار فعلاً پاسخ **مستندات** است و **فراخوانی ChatGPT و ساخت خودکار کد را اثبات نمی‌کند**. مقدار `chatgpt_invoked: false` عمداً ثبت می‌شود؛ اگر شواهد کافی نیست، `needs_human: true` برمی‌گردد. اشتراک ChatGPT صاحب گوشی را نمی‌توان برای همه کاربران به‌طور خودکار از GitHub Actions قرض گرفت.

**نکته فنی:** GitHub مخزن کد و اجرای *موقتی در زمان رویداد* را فراهم می‌کند. GitHub Actions سرور WebSocket دائم، اتصال صوتی بلادرنگ یا میزبان ChatGPT همواره فعال نیست. برای پاسخ خود مدل ChatGPT، اتصال مجاز SIWC با طرح کاربر لازم است؛ آن مسیر در نسخه قبلی به‌صورت اجرای خود میزبان توسعه یافته اما هنوز نصب/تأیید واقعی نشده است و خودبه‌خود در Actions دائمی اجرا نمی‌شود.

## درون برنامه

- حالت WSS: فقط با داشتن آدرس امن و توکن محدود؛ اگر موتور روشن و قابل‌دسترس باشد، پاسخ مدل از همان کانال می‌آید. قطع شبکه موجب جواب ساختگی نمی‌شود.
- حالت GitHub: در نبود اتصال WSS، از مخزن خصوصیِ از پیش متصل و تأییدشده استفاده می‌شود. این مسیر به روشن‌بودن ویندوز نیاز ندارد، ولی رویداد GitHub ممکن است تأخیر داشته باشد.
- در حالت «مکالمهٔ پیوسته»، ارسال خودکار متن به GitHub فقط پس از روشن‌کردن همان حالت و تأیید روشن مالک مجاز است.
- هیچ کلید OpenAI API پولی، خرید اشتراک، Codex یا Work به این تغییر اضافه نشده است.
- تغییرات موتور معاملاتی و سایر پروژه‌ها ممنوع و دست‌نخورده‌اند.

## قبولی

موفقیت CI تنها نشان می‌دهد که کد جاوا و گردش کار پشتیبانی اجرا شده و APK ساخته می‌شود. برای اعلام موفقیت کامل، باید برنامه روی گوشی Galaxy M62 واقعاً نصب شود، مکالمهٔ فارسی از سرویس گفتار گوشی شناسایی شود، گفتار فارسی واقعاً پخش شود، و **پاسخ مدل واقعی** از اتصال مجاز با شناسهٔ همان درخواست دریافت شود. کیفیت مشابه ChatGPT باید با فایل نمونهٔ مرجع و آزمون شنیداری سنجیده شود؛ با آزمون کد نمی‌توان آن را ثابت کرد.
