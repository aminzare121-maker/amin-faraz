# صدای فارسی هوش امین — نسخهٔ سبک بدون مدل حجیم

## وضعیت و مسیر واقعی اجرا
این نسخه فقط از سرویس‌های `SpeechRecognizer` و `TextToSpeech` خود اندروید استفاده می‌کند. هیچ فایل ONNX / Vosk / Piper یا مدل آفلاین بزرگ داخل APK، روی رایانه یا GitHub بارگذاری نمی‌شود.

سه گزینه در خود برنامه:
1. **آنلاین**: تشخیص گفتار فارسی با سرویس مجاز سیستم‌عامل؛ در صورت وجود، بهترین صدای فارسی شبکه‌ای نصب‌شده در TTS ترجیح داده می‌شود. ممکن است محتوای گفتار برای پردازش به ارائه‌دهندهٔ سرویس گفتار گوشی منتقل شود.
2. **آفلاینِ گوشی**: روی اندروید ۱۲ به بالا با `createOnDeviceSpeechRecognizer` و در صورت وجود سرویس محلی مناسب، صدا به متن تبدیل می‌شود؛ TTS فقط صدای فارسیِ `isNetworkConnectionRequired=false` را می‌پذیرد. **اگر چنین سرویس‌هایی نصب نباشند، حالت آفلاین کار نمی‌کند و دانلود پنهانی انجام نمی‌شود.** انتخاب آفلاین هرگز خودکار به سرویس تشخیص صدا یا TTS شبکه‌ای برنمی‌گردد.
3. **خودکار**: در صورت وجود سرویس گفتار محلی اندروید از آن استفاده می‌شود؛ در غیر این صورت سرویس گفتار عادی اندروید انتخاب می‌شود. مناسب زمانی که مالک استفادهٔ احتمالی از سرویس آنلاین گفتار گوشی را مجاز دانسته باشد.

حالت پیوسته پس از تشخیص مکث گفتار، متن را به **کانال WSS تأییدشده** می‌فرستد، یا با رضایت قبلی به **Issue مخزن خصوصیِ متصل به گوشی** می‌سپارد. در حالت Issue GitHub **صرف ثبت سؤال باعث اجرای مدل ChatGPT نمی‌شود**؛ وجود یک عامل آنلاین متصل و مجاز و ارسال پاسخ واقعی الزامی است.

وقتی WSS و مخزن خصوصی قطع‌اند، در حالت آفلاین فقط **فرمان‌های ثابت** «راهنما»، «وضعیت اتصال»، «خواندن پاسخ قبلی» پشتیبانی می‌شود. این یک مدل زبانی/ChatGPT آفلاین نیست و دربارهٔ هیچ موضوع تازه‌ای پاسخ ساختگی نمی‌دهد.

## موتور در GitHub
کد موتور، اتصال SIWC، ابزارهای GitHub، اپ گوشی و Windows در مخزن `aminzare121-maker/amin-faraz` ذخیره و با GitHub Actions ساخته می‌شوند. با اتصال گوشی به اینترنت، امکان دسترسی به **مخزن خصوصی مجاز** و ارسال/دریافت Issue وجود دارد؛ نه اینکه GitHub خودش یک فرآیند پاسخ‌گویی AI همیشگی را میزبانی کند.

**تفاوت حیاتی:** GitHub مخزن کد و اجرای موقتی Actions را می‌دهد، نه سرور دائمی ChatGPT یا کلید قانونی و رایگان inference. عامل `chatgpt_git_agent.py` برای استفاده از سهمیهٔ ChatGPT صاحب حساب با OAuth قانونی باید در محیطی که مالک به آن وارد شده و اینترنت فعال دارد، اجرا شود. فعلاً راه‌اندازی و آزمون واقعی آن روی گوشی یا لپ‌تاپ **تأیید نشده** است. برای سرویس آنلاین ۲۴ساعتهٔ بی‌نیاز از کامپیوتر، یک میزبان مجاز و احراز هویت مستقل لازم است؛ هیچ هزینه‌ای خودکار فعال نشده.

## کیفیت صدا و آزمون‌ها
تست‌های CI تنها سیاست انتخاب سرویس و ساخت APK را بررسی می‌کنند، نه کیفیت صدای شنیده‌شده. صدای فارسی در خروجی به TTS گوشی بستگی دارد و برابری با صدای مکالمهٔ ChatGPT **نه اثبات و نه تضمین شده است**. برای سنجش کیفی باید روی دستگاه واقعی با فایل‌های مرجع و گوش‌دادن مقایسه شود.

## وضعیت نصب
فایل APK آزمایشی GitHub Actions برای آزمایش دستی در بخش Artifacts هر اجرای موفق موجود است. ساخت موفق APK به معنی نصب آن روی Galaxy M62 نیست. مسیر قدیمی نصب مدل‌های پرحجم در شاخهٔ آزمایشی جدا باقی مانده و به شاخهٔ اصلی ادغام نشده است.
