# پل مستقیم به ChatGPT Work — بدون Codex / بدون OpenAI API

## مسیر اجرایی درخواست مالک

**ChatGPT مقصد هوش مرکزی است، نه Codex.** این مرحله از قابلیت رسمی **event-triggered tasks** در ChatGPT Work برای GitHub Pull Requests استفاده می‌کند. رویداد مستقیماً در ChatGPT Work پردازش می‌شود، ولی ثبت PR **خودش** نه ChatGPT را فراخوانی می‌کند و نه نتیجه تضمین می‌کند؛ باید وظیفهٔ رویدادمحور در حساب صاحب مخزن روشن، مجاز و واقعاً آزمایش شده باشد.

**مسیر آماده در کد:**
1. کاربر از موبایل یا ویندوز سؤال می‌فرستد. `AMIN_CHAT_BRIDGE_V1` در یک **Issue خصوصی** مخزن خودِ او ذخیره می‌شود.
2. کاربر در اپ روی «ارجاع درخواست خصوصی به ChatGPT Work» می‌زند، یا در ویندوز `direct_github_relay.py --repo OWNER/PRIVATE trigger-work --issue N --id 32HEX` را اجرا می‌کند.
3. پل یک شاخه با نام `amin-chatgpt-work/<request_id>` می‌سازد و تنها شناسه، شماره Issue و مجوز را در فایل `.amin-chatgpt-work/requests/<id>.json` ثبت می‌کند. **متن سؤال در commit و Pull Request تکرار نمی‌شود.**
4. Pull Request با عنوان `[Amin ChatGPT Work] <12hex>` در همان مخزن خصوصی باز می‌شود. اگر ChatGPT Work برای رویداد **opened PR** در این مخزن فعال باشد، قادر است رویداد را دریافت و Issue مرتبط را بررسی کند.
5. عامل ChatGPT Work، فقط در صورتی که ابزار نوشتن GitHub در همان حساب مجاز باشد، پاسخ را با قالب `AMIN_CHAT_REPLY_V1\n{...}` در **Comment همان Issue خصوصی** ثبت می‌کند. اپ فعلی پاسخ را از مسیر `status` / دریافت پاسخ نمایش می‌دهد. ناتوانی در نوشتن Comment، نداشتن اتصال، نیاز به تأیید یا شکست اجرای Work باید به‌عنوان **پاسخ‌نداده** ثبت شود.

## راه‌اندازی در ChatGPT (اقدام شخص صاحب حساب)

در `Settings → Plugins` دسترسی GitHub به مخزن خصوصیِ موردنظر را بررسی کنید. سپس در **ChatGPT Work** یک وظیفهٔ رویدادمحور GitHub بسازید با Trigger: **Pull request opened** برای مخزن مجاز. Conditions: فقط عنوان‌های `[Amin ChatGPT Work]` در مخزن خصوصی. Prompt پیشنهادی:

> برای هر PR جدید با عنوان `[Amin ChatGPT Work] ` و شناسه معتبر، فقط اگر مخزن خصوصی است و صاحب مخزن آن را ساخته، دادهٔ `AMIN_CHATGPT_WORK_PR_V1` در متن PR را بررسی کن. Issue شمارهٔ ذکرشده را از همین مخزن مجاز بخوان؛ قالب `AMIN_CHAT_BRIDGE_V1`، تطابق ۳۲ رقم شناسه، وجود رضایت و project را کنترل کن. اگر `test_only` است، پاسخ تولید نکن. درخواست را با ChatGPT بررسی کن. اگر فقط سؤال است، جواب فارسی شفاف و محدود به شواهد بده. اگر ساخت برنامه یا تغییر GitHub می‌خواهد، بدون مجوز جداگانهٔ اعمال تغییر، هیچ نصب، اجرا، انتشار یا معاملهٔ واقعی انجام نده. اگر مجوز نوشتن Comment داری، نتیجهٔ واقعی را تنها به همان Issue خصوصی در یک Comment `AMIN_CHAT_REPLY_V1` با `request_id`، `status:"answered"`، `answer` و `action_performed:false` بنویس؛ اگر مجوز نداری، ادعای پاسخ ارسالی نکن. برای درخواست‌های دیگر یا مخازن عمومی هیچ اقدامی انجام نده.

اگر رابط فعلی ChatGPT اجازهٔ ساخت این Trigger را نمی‌دهد، مسیر تا همین نقطه **غیرفعال** است. سازوکار زمان‌بندی ساعتی جایگزین خودکارِ این Trigger نیست.

## دسترسی‌ها و هزینه

- توکن GitHub برای **فعال‌سازی اختیاری PR توسط گوشی** باید به یک مخزن خصوصی محدود شده و دسترسی‌های `Issues:read/write`، `Contents:write` و `Pull requests:write` داشته باشد. برای فقط ارسال Issue و دریافت پاسخ، همان دسترسی محدود Issues کفایت می‌کند. این مجوزهای اضافی اختیاری‌اند و نباید برای همه مشتریان به‌طور پیش‌فرض داده شوند.
- ساختن PR با GitHub REST API هزینهٔ OpenAI API ندارد. استفاده از ChatGPT Work تابع سهمیه و مجوز همان حساب است. هزینهٔ GitHub یا محدودیت‌های اینترنت/مخزن خصوصی به‌صورت مستقل باید بررسی شود. پول یا خرید جدیدی از این کد انجام نمی‌شود.
- هر کاربر باید **حساب ChatGPT مجاز و GitHub خصوصی متعلق به خود** را داشته باشد. هیچ حساب/توکن مشترک برای مشتریان مجاز نیست؛ اشتراک مالک، سرویس مدل بدون سقف برای همه کاربران ایجاد نمی‌کند.

## وضعیت واقعی

- این مسیر **PR را ایجاد می‌کند**، اما نمی‌تواند دسترسی به همین گفت‌وگوی ChatGPT را از برنامهٔ شخص ثالث باز کند. **خودِ وظیفهٔ Work از داخل این ابزار برنامه‌نویسی ایجاد/تأیید نشده است.**
- **تأخیر و پاسخ آنی مشابه تلفن تضمین نیست**؛ ورود رویداد، اجرای Work، سهمیه و تأییدها ممکن است زمان ببرند.
- مکالمه صوتی پیوسته/دوطرفه با قطع گفتار هنوز وجود ندارد؛ گفتار اندروید در این مرحله به متن تبدیل می‌شود.
- تا زمان آزمون واقعی با یک PR و مشاهدهٔ پاسخ ChatGPT در همان Issue و همان گوشی، **پیوند ChatGPT عملیاتی کامل نیست**.
