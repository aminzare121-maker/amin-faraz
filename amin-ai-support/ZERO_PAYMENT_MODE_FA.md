# طرح اجرای «هوش پشتیبان امین» بدون وابستگی به پرداخت مالک

**دستور قطعی مالک:** GitHub مسترکارت مجازی موجود را نمی‌پذیرد؛ توسعه و اجرای آزمایشی برنامه نباید نیازمند پرداخت اجباری به GitHub، API پولی، سرور اجاره‌ای، کارت بانکی یا خرید اعتبار جدید باشد.

## معماری انتخاب‌شده

| بخش | روش بدون پرداخت اشتراک | نکته واقعی |
|---|---|---|
| کد و نسخه‌بندی | مخزن عمومی فعلی GitHub در طرح Free | فایل خصوصی و داده مشتری در مخزن عمومی قرار نمی‌گیرد |
| آزمون کد و ساخت APK | GitHub Actions با اجراکننده‌های استاندارد روی مخزن عمومی | اجرای همیشگی هوش یا دیتابیس تولیدی روی Actions ممنوع؛ اجراکننده بزرگ پولی ممنوع |
| موتور هوش | مدل دارای مجوز متناسب با استفاده تجاری، روی رایانه Windows مالک از طریق Ollama/سرویس محلی | مصرف برق، منابع CPU/RAM، دانلود اولیه مدل و اینترنت به‌طور کامل «هزینه صفر» نیست |
| دانش و حافظه | SQLite و فایل‌های محلی با پشتیبان‌گیری روی رایانه مالک | بدون ارسال اسناد داخلی به GitHub عمومی |
| دسترسی مشتری | ابتدا روی رایانه/شبکه محلی و آزمایش محدود، نه وعده سرویس عمومی ۲۴ساعته | دسترسی جهانی پایدار نیازمند شبکه، امنیت و احتمالاً زیرساخت دیگری است |
| درآمد مشتری | سهمیه و اعتبار هر مشتری در موتور، با تأیید واقعی دریافت وجه توسط مالک | درگاه بانکی واقعی هنوز متصل نیست؛ GitHub هیچ حق مستقیم از فروش مشتری دریافت نمی‌کند |

## حفاظت فنی واقعی در کد

**حالت AMIN_ZERO_PAYMENT_MODE به‌صورت پیش‌فرض ON است.** در این حالت، موتور به هیچ مدل هوش خارجی، حتی اگر آدرس HTTPS، کلید API و رضایت کاربر تنظیم شده باشد، درخواست ارسال نمی‌کند. تنها API روی خود دستگاه (`localhost`، `127.0.0.1` یا `::1`) مجاز است. اگر مدل محلی نصب نشده باشد، خروجی راهنمای مبتنی بر مستندات و ارجاع انسانی باقی می‌ماند؛ مدل ساخته یا نصب‌شده ادعا نمی‌شود.

برای حفظ قابلیت قبلی توسعه، خاموش‌کردن این محافظ با `AMIN_ZERO_PAYMENT_MODE=off` همچنان از نظر کد ممکن است، اما **مخالف هدف بدون پرداخت مالک است و نباید بدون اجازه صریح مالک انجام شود**؛ حتی آن‌وقت هم موافقت مدیر و رضایت هر درخواست برای مدل خارجی لازم است.

فایل `audit_free_github.py` روی تمام Workflowها بررسی ایستا انجام می‌دهد: فقط اجراکننده استاندارد GitHub در مخزن عمومی یا برچسب‌های شناخته‌شده خودمیزبان پذیرفته می‌شوند. این کنترل هیچ‌گونه دسترسی به صورت‌حساب GitHub ندارد و به‌تنهایی تضمین عدم صدور هزینه نیست.

## راه‌اندازی روی Windows بدون پرداخت API

فایل `windows/Start-AminSupport-Free.ps1` فقط بررسی می‌کند Python، Ollama و مدل انتخابی **از پیش** در دسترس باشند؛ هیچ نصب یا دانلود یا خریدی انجام نمی‌دهد. پس از بررسی شرایط، آدرس محلی مدل را تنظیم کرده و رابط فارسی را فقط روی `127.0.0.1:8765` باز می‌کند. ممکن است برای مدل ۷ میلیارد پارامتری روی CPU پاسخ‌ها کند باشند؛ مناسب بودن سرعت و کیفیت آن روی لپ‌تاپ مالک هنوز آزمایش نشده است.

روش آزمایشی فقط در محیط امن مالک:
```powershell
cd path\to\amin-ai-support
.\windows\Start-AminSupport-Free.ps1
```
به علت نیاز به اتصال و دانلود اولیه مدل، این دستورات به‌تنهایی نصب کامل سرویس را انجام نمی‌دهند.

## کنترل مخارج GitHub که باید در خود حساب تأیید شود

در GitHub، تنظیمات **Settings → Billing and licensing → Budgets and alerts** را بررسی و در صورت پشتیبانی از بودجه صفر یا حد مجاز مناسب، گزینه **Stop usage when budget limit is reached** را برای محصولات هزینه‌دار فعال کن. **من در این مرحله به تنظیمات صورتحساب شخصی دسترسی ندارم و آن‌ها را تغییر نداده‌ام.** اگر سقف صفر در یک نوع بودجه قابل ثبت نباشد، نباید آن را به‌عنوان تنظیم‌شده اعلام کنیم. مخزن نباید خصوصی یا اجراکننده بزرگ‌تر شود مگر با بررسی شرایط مالی.

منابع رسمی:
- https://docs.github.com/en/billing/concepts/product-billing/github-actions
- https://docs.github.com/en/billing/how-tos/set-up-budgets
- https://docs.github.com/en/actions/concepts/runners/larger-runners

## معیار قبولی و باقی‌مانده‌ها

- **کد حالت بدون پرداخت:** پس از موفقیت CI و ادغام قابل تأیید است.
- **کارکرد مدل روی لپ‌تاپ:** هنوز با سخت‌افزار مالک آزمایش نشده است.
- **هزینه صورتحساب GitHub:** در ابزارهای این گفتگو به صورت مستقیم قابل خواندن/قفل‌کردن نیست.
- **سرویس تجاری دائمی برای مشتریان اینترنتی بدون هزینه از جیب مالک:** هنوز اثبات نشده؛ اگر ظرفیت سخت‌افزاری، اینترنت و درآمد مشتریان کافی نباشد، ممکن است این هدف امکان عملی نداشته باشد.
- **هیچ پرداخت، کارت جدید یا اشتراک پولی نباید برای پیاده‌سازی این مرحله لازم باشد.**

این سند قرارداد هزینه است؛ شاخص‌های امنیت و کیفیت پاسخ، صوت فارسی، چندمدیری، افزایش هوشمندی و پایایی پروژه حذف یا تضعیف نشده‌اند.
