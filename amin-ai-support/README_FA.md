# هوش پشتیبان امین — نسخهٔ اجرایی اولیه 0.1

**تاریخ ایجاد:** 2026-11-22  
**جایگاه:** پوشه مستقل در مخزن amin-faraz، شاخه توسعه؛ بدون تغییر موتورهای معاملاتی.
**وضعیت:** سورس اولیه و آزمون‌های خودکار؛ نه پشتیبان تجاری تأییدشده و نه جایگزین کامل ChatGPT/Codex.

## هدف ثابت مالک

یک موتور مشترک که برای هر محصول حافظه، مجوز، ابزار عیب‌یابی و پاسخ‌گویی فارسی جدا داشته باشد. توسعه و پشتیبانی پروژه‌ها باید از نسخه واقعی کد و شواهد قابل ردیابی پیروی کند. سابقه تصمیم‌های ChatGPT و Codex صرفاً تا حدی قابل استفاده است که در فایل، Issue، PR، گزارش آزمون یا منابع مجاز دیگری ثبت شده باشد؛ امکان انتقال مستقیم «تمام ادراک» درونی مدل‌ها وجود ندارد.

## قابلیت‌های پیاده‌سازی‌شده در نسخه 0.1

1. پنج شناسه مستقل: فراز، آرتین، V5، کابین متاتریدر و اپ راهبردی ایران.
2. اتصال هر شناسه به شاخه واقعی GitHub مخصوص خود (به‌جز اپ راهبردی که مخزنش هنوز در این نسخه مشخص نشده است).
3. دریافت مخزن و ساخت نمایه مجزای SQLite برای هر پروژه از راه فرمان sync؛ و به‌روزرسانی دوره‌ای با auto_sync.py وقتی آن فرایند واقعاً در حال اجراست.
4. جداسازی مستندات عمومی از کد و اسناد مخصوص توسعه‌دهندگان.
5. سؤال‌وجواب فارسی همراه استناد به مسیر فایل‌های پیدا شده؛ اگر شواهد کافی نباشد سیستم کمبود اطلاعات را اعلام می‌کند.
6. اتصال اختیاری مدل زبانی سازگار با OpenAI API، شامل سرور محلی؛ بدون مدل، حالت جستجوی اسناد همچنان اجرا می‌شود.
7. تشخیص اولیه چند خانواده خطا و بررسی **صرفاً نحوی** فایل‌های پایتون؛ بدون اجرای خودسرانه کد کاربر.
8. رابط وب فارسی واکنش‌گرا؛ ورودی و خروجی صوتی از قابلیت مرورگر، در صورت وجود صدای فارسی در دستگاه.
9. آزمون‌های آفلاین جداسازی پروژه‌ها، جلوگیری از افشای منابع داخلی، احراز هویت HTTP، کنترل ورودی و عیب‌یابی نحوی.

## اجرای محلی

پیش‌نیاز: Python 3.11+ و Git. برای اجرای محلی پایه، کتابخانه Python اضافی لازم نیست.

~~~bash
cd amin-ai-support
python -m unittest discover -s tests -v
python amin_support.py sync --project faraz
python amin_support.py ask --project faraz --message "موتور فراز چه وضعیت مستندی دارد؟"
python amin_support.py serve
~~~

صفحه محلی: http://127.0.0.1:8765

برای افزودن نمایه آرتین، V5 یا کابین، به‌جای faraz شناسهٔ همان پروژه را وارد کنید. اجرای sync بدون شناسه، همه پروژه‌های دارای شاخه GitHub تعریف‌شده را بررسی می‌کند. sync به GitHub دسترسی شبکه نیاز دارد. اگر اتصال برقرار نباشد، دانش موجود از بین نمی‌رود.

برای به‌روزرسانی خودکار تا زمانی که فرایند اجراست:

~~~bash
python auto_sync.py --interval-seconds 21600
~~~

### اتصال به مدل هوش مصنوعی

**موتور مدل داخل این مخزن قرار ندارد.** برای تولید پاسخ تحلیلی، می‌توان مدل مجاز را روی سرور خود یا از سرویس سازگار با API متصل کرد:

~~~bash
export AMIN_MODEL_BASE_URL="http://127.0.0.1:11434/v1"
export AMIN_MODEL_NAME="YOUR_INSTALLED_MODEL"
export AMIN_MODEL_API_KEY=""
python amin_support.py serve
~~~

این مثال فقط قالب اتصال است؛ وجود یا نصب هیچ مدل خاصی را ادعا نمی‌کند. برای مدل بیرونی HTTPS الزامی است؛ ارسال مستندات و متن سؤال به سرویس بیرونی باید با رضایت و سیاست حریم خصوصی سازگار باشد. ورود صوتی مرورگر نیز ممکن است از سرویس ابری خود مرورگر استفاده کند و عملکرد آن با اینترنت محدود، تضمین‌شده نیست.

### امنیت و استفاده عمومی

- اجرای سرور به‌طور پیش‌فرض فقط روی 127.0.0.1 است. اگر روی نشانی عمومی یا شبکه باز شود، AMIN_SUPPORT_API_KEY اجباری می‌شود؛ اما کلید مشترک به‌تنهایی **احراز هویت تولیدی کاربران** نیست.
- برای عرضه واقعی باید HTTPS، حساب مستقل کاربران، جداسازی مستاجرها، محدودسازی درخواست، سیاست حذف اطلاعات و رصد امنیتی اضافه شود.
- API عمومی فقط نقش customer دارد؛ حتی اگر درخواست role=developer بفرستد. ابزارهای توسعه و عیب‌یابی از خط فرمان مدیر اجرا می‌شوند.
- فایل .env، کلید خصوصی، داده حجیم و مسیرهای نامرتبط وارد نمایه نمی‌شوند؛ الگوهای رایج رمز نیز پیش از ذخیره حذف می‌شوند. این فیلتر **ممیزی کامل اسرار نیست**؛ مخزن محرمانه نباید بی‌بررسی نمایه شود.
- هیچ دستور عملیاتی، اصلاح سورس، ارسال سفارش معاملاتی، تغییر حساب یا استقرار عمومی بدون کنترل جداگانه اجرا نمی‌شود.
- صدای فارسی مبتنی بر قابلیت مرورگر است؛ کیفیت، آفلاین‌بودن یا موجودبودن آن هنوز تضمین نشده است.

## شاخص‌های قبولی پیش از استفاده تجاری

- آزمون با مسائل واقعی هر پروژه؛ هدف پیشنهادشده دست‌کم 85٪ پاسخ درست و مستند بر اساس مجموعه آزمون از پیش تعریف‌شده.
- صفر پاسخ بین‌پروژه‌ای، صفر افشای داده محرمانه در تست امنیت، صفر تغییر حساس بدون مجوز.
- ارزیابی جداگانه کیفیت گفتار فارسی، تشخیص خطا، هزینه مدل، سرعت و پایداری شبکه.
- بررسی پروانه نرم‌افزار و مدل‌ها برای استفاده تجاری.

**این معیارها هنوز پاس نشده‌اند.** اجرای موفق چند تست واحد به‌معنای تأیید عملکرد واقعی یا آمادگی کاربران نیست.

## مراحل تکمیل باقی‌مانده

- استخراج دقیق‌تر سوابق ChatGPT/Codex از اسناد ثبت‌شده و افزودن پیوند commit/PR/Issue به دانش؛ کد به‌تنهایی شامل تمام تاریخچه تصمیم‌گیری نیست.
- تکمیل اسناد عمومی *تأییدشده* برای هر محصول؛ بسیاری از فایل‌های فعلی توسعه‌ای‌اند و نباید برای مشتری باز شوند.
- افزودن سامانه تیکت، بازخورد، گردش کار اصلاحیه و تأیید انسانی، محیط تست ایزوله و استقرار کنترل‌شده.
- آزمایش مدل فارسی/فنی با مجوز تجاری مناسب، تست صوت و آزمایش End-to-End واقعی.
- تعیین مخزن اپ راهبردی ایران و سایر برنامه‌های آینده پس از شناسایی قابل‌اعتماد پروژه، بدون حدس.
