# آزمایش مدل واقعی روی اسناد واقعی فراز و آرتین

**پرونده برنامه جواب:** [#73](https://github.com/aminzare121-maker/amin-faraz/issues/73)

این ابزار در مسیر `real_source_benchmark.py` با مدل واقعاً در حال اجرا، **پنج سناریوی محدود** را بر مبنای دو سند GitHub بررسی می‌کند:

- فراز: `FARAZ_STATUS_AND_HANDOFF_FA.md` در شاخه مورد آزمایش
- آرتین: `tools-makhzan/INDEX_FA.md` از شاخه `tools-makhzan-hub`

چهار سؤال به دنبال واقعیت مشخص با سند معتبر هستند و یک سؤال، عدم افشای داده میان دو پروژه را آزمایش می‌کند. خروجی شاخص‌های «مدل واقعاً استفاده شد»، «پاسخ درست»، «مسیر سند معتبر»، «ارجاع سؤال بی‌ارتباط» و زمان پاسخ را بدون چاپ متن محرمانه در گزارش CI ثبت می‌کند.

گردش‌کار `amin-real-source-benchmark.yml` فقط روی GitHub Actions، مدل محلی موقت `qwen2.5:7b-instruct` را اجرا می‌کند. برای کاهش هزینه و مصرف منابع، آزمایش روی هر تغییر محصول اجرا نمی‌شود؛ تنها تغییر این آزمون یا فراخوان دستی آن را اجرا می‌کند.

**محدودیت صریح:** اجرای موفق گردش‌کار نشان‌دهنده پایان اجرای آزمایش است، نه گذر از معیار کیفیت. کلید `target_met_on_pilot` و درصد `measured_pass_rate` باید جدا خوانده شوند. اگر کمتر از ۸۵٪ باشد، کیفیت همین مجموعه آزمون نیز به آستانه پیشنهادشده نرسیده است. اگر ۱۰۰٪ باشد، باز هم پنج سؤال کافی برای ادعای «قابل اتکا بودن» یا عرضه تجاری نیست.

اجرا با مدل موجود:
```
python real_source_benchmark.py --faraz-doc ../FARAZ_STATUS_AND_HANDOFF_FA.md --artin-doc /path/to/INDEX_FA.md --report benchmark.json
```
با `--strict` برنامه در صورت گذرنکردن معیار ۸۵٪ با کد ناموفق خارج می‌شود. در حالت پیش‌فرض گزارش اندازه‌گیری تولید می‌کند؛ **نتیجه شکست را پنهان نمی‌کند**.

موارد لازم پیش از عرضه: مجموعه آزمون حداقل چند ده مسئله واقعی و پاسخ مرجع مستقل از مدل، بازبینی انسانی، آزمون‌های امنیت/حریم خصوصی، کیفیت صوت فارسی و استقرار پایدار روی شبکه واقعی کاربر.
