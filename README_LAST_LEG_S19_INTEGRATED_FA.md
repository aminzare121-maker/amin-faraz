# بخش «آخرین لگ و نیمه آن» در موتور آرتین — ۱۱ نوامبر ۲۰۲۶

این بخش **به موتور فعلی، نه یک موتور جدید** اضافه شده است. برای کندل‌های بسته M15، پیوت‌های هندسی سه‌کندلی را با مقایسه دقیق قیمت شناسایی می‌کند؛ اگر دو پیوت اخیر از نوع مخالف باشند، بازه لگ احتمالی و نیمه قیمتی آن را محاسبه و بسته‌شدن سه کندل بعدی را با نیمه مقایسه می‌کند. فقط داده‌هایی که تا زمان بسته‌شدن کندل در دسترس بوده‌اند استفاده می‌شوند. اگر گسست زمانی باشد، پیوت‌های قبلی دیگر به عنوان یک توالی پیوسته به کار نمی‌روند. این مقادیر در خروجی موتور زیر `teacher_review.automatic_last_leg` گزارش می‌شوند.

## منبع خود مدرس

- `Technical(1).pdf` صفحات ۲، ۴ و ۵: پیوت، روند و پولبک، به عنوان منبع تصویری-متنی شکل‌ها.
- جلسه ۱۹، متن پیاده‌سازی ماشینی زمان‌دار، ثانیه‌های **۳۵۰۰٫۸۲ تا ۳۵۲۳٫۷۰**: شرط سه کندل و نیمه آخرین لگ؛ حداقل یک کندل تردید در جهت سنتیمنت.
- جلسه ۱۹، متن ماشینی ثانیه‌های **۳۶۲۳٫۲۸ تا ۳۶۵۴٫۲۸**: بررسی ورود در بسته‌شدن کندل سوم و ضرورت تشکیل پیوت.
- جلسه ۱۹، متن ماشینی ثانیه‌های **۴۲۷۳٫۲۶ تا ۴۲۹۹**: عبور نکردن بسته‌شدن کندل از نیمه لگ، بسته به موقعیت آموزشی نشان داده‌شده.

توجه: متن گفتار، خروجی ASR است و هنوز به معنای تایید مستقل شنیداری/تصویری تمام موارد نیست. `midpoint` از دو پیوت **کاندیدای هندسی** محاسبه می‌شود، نه لگی که مدرس لزوماً انتخاب می‌کند. انتخاب لگ معتبر مدرس، پیوت ماژور/مینور و سنتیمنت اقتصادی از شکل کندل حدس زده نمی‌شود. تا آن‌ها و سایر شروط ۱۳ مسیر روشن نشوند، `trade_authorized=false` و `broker_orders_authorized=false` باقی می‌مانند.

## آنچه واقعاً آزموده شد

- ۸ آزمون اختصاصی لگ: عدم استفاده از آینده، تعیین نیمه دقیق، سه بسته‌شدن، پیوت‌های مبهم، دو پیوت هم‌نوع، داده تکراری/خراب، گسست زمانی، تأیید مسدودبودن سفارش.
- آزمون محلی عادی و `python -O`؛ به علاوه آزمون‌های بازگشتی موتور قبلی و ۱۴۷ آزمون هسته.
- بازپخش خصوصی ۲۳٬۶۴۳ کندل تاریخی ثبت‌شده: `ARTIN_S19_LAST_LEG_REPLAY_AGGREGATE_20261111.json`. گزارش فقط شمارش‌ها و هش منبع دارد؛ کندل‌های خام، شماره حساب و لاگ خصوصی در GitHub منتشر نمی‌شوند.
- آزمون MetaTrader واقعی، ارسال سفارش DEMO، تایید معنایی همه ۲۵ جلسه و سوددهی در این مرحله انجام نشده است.

## نحوه اجرای محلی آزمون

از پوشه اصلی بسته با Python 3.11:

```bash
python -m unittest -q test_artin_teacher_last_leg_observer test_artin_teacher_13route_live_gate
python -O -m unittest -q test_artin_teacher_last_leg_observer test_artin_teacher_13route_live_gate
```

فایل اصلی تشخیص: `artin_teacher_last_leg_observer.py`؛ اتصال به موتور: `artin_teacher_13route_live_gate.py`؛ دریافت و مشاهده MT5 DEMO: `artin_mt5_demo_automatic.py`. حالت پیش‌فرض سفارش غیرفعال است. **این بسته تأیید نهایی موتور طبق کل آموزش مدرس نیست.**
