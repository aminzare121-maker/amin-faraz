**محدودیت مهم:** جدول صفحهٔ ۴ بازه‌های متداخل/نامشخص `50%`، `50–61%`، `60–100%` و یادداشت `>66%` دارد. برای مقادیر مبهم هیچ نسبت سود/ضرر خودکار انتخاب نمی‌شود. انتخاب شاخهٔ سه‌هدفه نیز به تأیید منبع نیاز دارد. موتور برای توقف و جابه‌جایی SL از BID در BUY و ASK در SELL استفاده می‌کند؛ نتیجهٔ برخورد، صرفاً trigger کاغذی است، نه تضمین fill یا سود محقق‌شده.

## اجرای ویندوز برای پرونده‌های فعلی مدرس

ساختار پوشه باید مانند ZIP تحویلی باشد (فایل PDF کنار فایل CMD و آرشیو خصوصی در `private/`). فایل زیر را اجرا کنید:

`run_artin_fxm_teacher_motor.cmd`

این فایل با **موجودی نمایشی ۱۰۰۰ دلار و ریسک ۱٪، تنها برای نمایش قوانین جزوه** اجرا می‌شود؛ نه موجودی حساب واقعی یا DEMO مالک. برای اعداد دیگر، CLI را با گزینه‌های `--balance`، `--reference-balance` و `--risk-percent` اجرا کنید.

روش مستقیم:

```cmd
python artin_fxm_teacher_motor.py --private-citations "private\ARTIN_13_ROUTE_24_CITATION_PRIVATE_REVIEW_20261110.json" --classroom-cases "private\ARTIN_13_CLASSROOM_CANDIDATE_CASES.json" --pinned-core core --fxm-pdf FXM.pdf --balance 1000 --reference-balance 1000 --risk-percent 1 --style DAY_TRADE --teacher-action-events "private\ARTIN_SOURCE_GROUNDED_ENTRY_EXIT_EVENTS.json" --original-25-sessions-dir "private\source_sessions" --out "private\fxm_motor_once.json"
```

هر اجرای تکراری باید نام خروجی **جدید** داشته باشد تا فایل گزارش قبلی بازنویسی نشود.

## نسبت این بسته با اصل هدف مالک

- **ساخته و آزموده:** منطق عملی مدیریت سرمایه، اندازه‌گیری حجم بر اساس حد ضرر ساختاری، توقف معامله، زمان‌بندی آموزشی، سه‌سطح TP و تغییر SL؛ اتصال به ۱۳ مسیر موجود و گزارش تصمیم‌های واقعی ۱۵ پروندهٔ موجود.
- **بدون ادعای موفقیت:** ۱۵ پروندهٔ فعلی کلاس دارای زمینهٔ نموداری و تأیید معنایی کافی نیستند، بنابراین `0` دستور ورود صادر شد. این نشانهٔ رعایت فیلتر است، نه سوددهی موتور.
- **تکمیل‌نشده:** استخراج و تطبیق مستقل تمام گفتار و تصاویر چهار ویدئوی تازه و ۲۵ جلسهٔ اصلی، تأیید ورود و خروج مدرس روی مثال واقعی، کامپایل/اجرای این نسخه به‌عنوان اکسپرت معاملاتی MT5 و آزمون واقعی سود و زیان. این پروژه همچنان کامل نیست.

در چهار ویدئوی پیوست فریم‌های نمونه دیده شد، ولی **صوتِ کامل این فایل‌ها در این مرحله پیاده‌سازی/تأیید معنایی نشده**؛ بنابراین جزوهٔ FXM منبع قطعی این الحاقیه است. نسخهٔ تاریخی کد و شاخهٔ مستقل Codex تغییر نکرده‌اند.
