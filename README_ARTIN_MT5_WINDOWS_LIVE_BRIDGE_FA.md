# آرتین V13 — اتصال محلیِ بدون معامله از جمع‌آورنده MT5 به بایگانی V5

**دامنه:** این ابزار کدهای V2، V3، V4 و V5 را تغییر نمی‌دهد؛ فقط به آن‌ها متصل می‌شود. هیچ سفارش معاملاتی ارسال نمی‌کند؛ تایید قواعد ۱۳ مسیر همچنان مسدود است.

## پیش‌نیاز اجرای واقعی در ویندوز مالک

1. MetaEditor باید **واقعاً** ابزار V3 را روی همان رایانه کامپایل کند و خروجی EX5 با لاگ معتبر تولید شود؛ آزمون‌های GitHub جای آن نیستند. فایل مربوط به جمع‌آوری کندل: `ArtinV13_ShadowProbe_RecoveryV2_DemoOnly.mq5`.
2. کاربر باید اکسپرت جمع‌آورنده را **در حساب MT5 DEMO روی نمودار XAUUSD و تایم‌فریم M15** فعال کند و تولید فایل CSV را مشاهده کند. این پل از داده CSV نمی‌تواند هویت واقعی سرور یا نوع حساب را مستقلاً احراز کند.
3. Python 3.11 یا بالاتر و فایل‌های `artin_mt5_local_observer_launcher.py`، `artin_mt5_durable_outbox_v5.py`، `artin_mt5_incremental_observer_v4.py` و `artin_mt5_shadow_bridge.py` باید کنار هم باشند.
4. روی `run_artin_mt5_demo_observer.cmd` دوبار کلیک شود. تا زمانی که پنجره باز است، فایل CSV موجود بررسی و هر دسته کندل جدید در خروجی پایدار V5 ذخیره می‌شود. اجرای پس‌زمینه پس از بسته‌شدن پنجره **فراهم نشده** و ادعا نمی‌شود.

در حالت عادی فایل CSV را از `%APPDATA%\MetaQuotes\Terminal\Common\Files\` پیدا می‌کند. اگر چند خروجی حساب/سرور موجود باشد، با پیام `MULTIPLE_ARTIN_V2_DEMO_CSV_FILES` متوقف می‌شود و باید مسیر را صریح بدهید؛ به‌طور تصادفی حساب انتخاب نمی‌کند.

اجرای دستی برای یک حساب مشخص:

```powershell
python artin_mt5_local_observer_launcher.py --csv "C:\MT5-Common-Files\artin_v13_demo_SERVER_123_XAUUSD_M15_recovery_v2.csv" --watch
```

آزمون یک‌باره بدون پایش:

```powershell
python artin_mt5_local_observer_launcher.py
```

بایگانی و وضعیت در `%LOCALAPPDATA%\ArtinV13\read-only-live\source_<شناسه>\` ساخته می‌شوند: `progress.json` و پوشه `evidence` با گزارش‌های `batch_...json`. وضعیت را برای ادامه پس از خاموشی حذف نکنید.

### رفتار خطا و مرز تأیید

- فایل ناقص یا در حال نوشتن حداکثر شش بار مجدداً بررسی می‌شود؛ خرابی قطعی، تغییر سابقه و هش نامعتبر اجرای پایش را **متوقف** می‌کند.
- اگر CSV هنوز ایجاد نشده است، ابزار فقط گزارش نقص می‌دهد؛ جمع‌آورنده MT5 را نصب یا به چارت وصل نمی‌کند.
- موفقیت آزمون‌های واحد، به معنی آزمون واقعی روی ویندوز مالک، کامپایل MetaEditor، اتصال بروکر Eplanet، اعتبار معنای مدرس یا رسیدن به هدف سه دقیقه نیست.
- آزمون این پل روی داده ساختگی صرفاً صحت اتصال نرم‌افزاری و بازیابی V5 را بررسی می‌کند.
- هیچ معامله‌ای ارسال نمی‌شود.
