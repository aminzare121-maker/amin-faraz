# موتور یکپارچه آرتین — اجرای تصمیم تا خروج کاغذی

**وضعیت دقیق:** این نسخه یک موتور رخدادمحور Python است که از ۱۳ مسیر اصلی آرتین (بدون دست‌کاری)، `Technical(1).pdf` (صفحه‌های ۱۳–۱۷) و `FXM.pdf` (صفحه‌های ۲–۷) استفاده می‌کند. مرحلهٔ ثبت ورود فرضی، جابه‌جایی حد ضرر و محاسبه سود/زیان **مدل کاغذی** را انجام می‌دهد. این یک اکسپرت قابل معامله در MT5 نیست و ارسال سفارش ندارد؛ آزمون درآمدزایی واقعی هم نشده است.

## آنچه واقعاً پیاده‌سازی شده

۱. دریافت رخداد `SETUP` همراه ارجاع زمانی و اطلاعات نمودار، و عبور آن از **همان هسته ۱۳مسیره پین‌شده**. اگر هر شرط معلوم نباشد، ورود مسدود می‌شود.

۲. تطبیق با خانوادهٔ ورود **REVERSAL** یا **BREAK** در Technical، کنترل قیمت ورود و حد ضرر **ساختاری** از خود نمودار، و تعیین حجم با ۱ تا ۲٪ ریسک موجودی طبق FXM. حد ضرر برای تناسب با حجم جابه‌جا نمی‌شود.

۳. انتخاب **SINGLE_RR** فقط در بازه واضح نرخ بردِ جدول FXM، یا **THREE_TP** در شاخه صریح صفحه ۴. در حالت دوم TP1/TP2/TP3 برابر `0.8R, 1.3R, 1.8R`، انتقال SL به ورود و سپس TP1 و در نهایت اعلام خروج کامل است.

۴. ورود فرضی فقط با رخداد `FILL` و قیمت دقیق منطبق با طرح پذیرفته می‌شود؛ ورود واقعی یا پرشدن سفارش ادعا نمی‌شود. `QUOTE` تنها با قیمت BID/ASK و زمان و منبع مشخص پردازش می‌شود؛ لمس SL/TP به‌تنهایی معامله را «بسته‌شده» نمی‌کند، بلکه رخداد بعدی `EXIT_FILL` برای ثبت نتیجه **مدل کاغذی** لازم است.

۵. توقف پس از افت دست‌کم ۲۰٪ از موجودی مرجع و قواعد توالی روزانه FXM. ورود دوم درحالی‌که یک طرح/معامله فعال وجود دارد مسدود است. قیمت، هزینه، شناسه روز معاملاتی، نرخ برد و مشخصات قرارداد باید از ورودی منبع‌دار بیایند؛ هیچ مقدار بازار یا آستانهٔ قدرت کندل اختراع نمی‌شود.

۶. لاگ رخدادها با زنجیره SHA-256 و تشخیص تغییر، حفاظت در برابر زمان آینده یا رخداد تکراری و بررسی فایل‌های اصلی PDF با SHA-256. هر دو PDF داخل ZIP محلی هستند؛ برای حفاظت از حقوق و اطلاعات کاربر در مخزن عمومی GitHub منتشر نشده‌اند.

## نحوه اجرا در Windows

Python 3 لازم است و فایل‌های بسته باید در یک پوشه استخراج شوند.

- برای دیدن کارکرد ساختگی موتور، فقط برای آزمایش نرم‌افزار: `run_artin_motor_synthetic_test.cmd`.
- برای داده **منبع‌دار واقعی**: فایل JSON موردنظر را به عنوان ورودی به `run_artin_unified_paper_motor.cmd "path\to\events.json"` بدهید. ورودی با ساختار نمونه پوشه `examples/` یکسان است، ولی منابع و شرایط باید مشاهده و تأیید شوند.
- فرمان مستقل:

```
python artin_unified_paper_motor.py --events "events.json" --pinned-core "core" --out "private/paper_run_001.json"
```

نام فایل خروجی موجود را دوباره استفاده نکنید؛ برنامه آن را بازنویسی نخواهد کرد. بدون فایل رخدادهای بازار و شواهد معتبر، موتور معامله‌ای باز نمی‌کند.

## آزمون و محدودیت، بدون ادعای اضافه

آزمون مسیرهای BUY/SELL، برنامهٔ RR تکی و سه‌مرحله‌ای، BID/ASK، استاپ، جلوگیری از ورود تکراری و داده آینده، توقف حساب، رد قیمت ورود تغییر‌یافته، هش فایل‌ها و یکپارچگی گزارش وجود دارد. همچنین ۱۴۷ آزمون موجود هسته قبلی بدون تغییر باید اجرا شوند.

**مبنای سود گزارش نمونه، بازار واقعی نیست.** مثال `examples/SYNTHETIC_TEST_ONLY_FXM_TP_LADDER.json` با قیمت‌های ساختگی عمداً نشان می‌دهد کد در TP1 و TP2 چه می‌کند و چگونه به TP3 می‌رسد. سود نمونه فقط یک محاسبهٔ حسابداری فرضی است.

**کارهای هنوز تأییدنشده و در این نسخه انجام‌نشده:** تفسیر کامل گفتار و نمودار همه ۲۵ جلسه، بازسازی علائم چارت طبق فرمول دقیق مدرس از OHLC خام، ایجاد سیگنال خودکارِ معتبر روی همه کندل‌ها، اکسپرت قابل کامپایل برای سفارش DEMO، اتصال/اجرای عملی این نسخه در MetaEditor/MT5، بک‌تست سوددهی واقعی. بدون شواهد، نتیجه `BLOCKED` می‌شود. PDF جایگزین مرجع آموزشیِ ویدئوی هنوز تأییدنشده است ولی نمی‌تواند اطلاعات بازار را از هیچ بسازد.

## حد جداسازی

نسخه Codex مستقل و فایل‌های قدیمی دست‌نخورده‌اند. موتور Python از ماژول‌های پین‌شده در `core/` استفاده می‌کند و هش همه سورس‌های اصلی را پیش از تصمیم کنترل می‌کند. سورس‌های PDF و ویدئوی مالک در GitHub عمومی قرار نمی‌گیرند. این کد هیچ `order_send`/معامله‌ای ندارد.

## تحویل یک‌کلیک و حد شواهد

روی ویندوز، برای آزمایش خود موتور بدون ارسال سفارش، فایل `run_artin_motor_selfcheck.cmd` را اجرا کنید. این کار آزمون‌های موتور و هسته پین‌شده را اجرا و فقط **یک معامله ساختگی** را برای بررسی گردش ورود تا خروج ثبت می‌کند. اجرای نمونه هرگز سود واقعی یا آزمون MT5 محسوب نمی‌شود.

در GitHub، `.github/workflows/artin-unified-paper-engine-ci.yml` کد هسته را از commit دقیق `b48fb06f8b2b0d134292025f5b27fc670ad2a293` بازمی‌آورد و تست آفلاین را روی Windows و Ubuntu اجرا می‌کند. هیچ ویدئو، PDF مالک یا داده کندل خصوصی در GitHub عمومی قرار نمی‌گیرد.
