# اتصال بررسی ۱۳ مسیر مدرس به موتور خودکار MT5 DEMO

**این تغییر مستقیماً نقص اجازه سفارش از روی تنها دو الگوی PDF را برطرف می‌کند.**

## رفتار اجرایی

در هر کندل بسته M15 از ePlanet DEMO، موتور طبق قبل الگوهای قابل‌اندازه‌گیری PDF Technical را پیدا می‌کند و **همان کندل‌ها** را به نسخه اصلاح‌شده هسته ۱۳مسیره (`teacher_s19/teacher_core_s19`) می‌دهد. هسته همه ۱۳ روش را برای BUY و SELL می‌سنجد (۲۶ تصمیم در هر کندل)؛ برای هر مورد وضعیت و وابستگی‌های گمشده گزارش می‌شود. شرط سه‌کندلی و پیوت جلسه ۱۹ در همین هسته قرار دارد. منابع PDF مربوط به مدیریت ریسک/حد سود و حد ضرر FXM به همان شکل سابق حفظ شده‌اند.

**مرز واقعی:** منابع صوتیِ استخراج‌شده ۲۵ جلسه و فریم‌های موجود، برای تمام شروط مستقل و کامل تأیید معنایی نشده‌اند. جنس داده ماشین ASR به معنای تأیید انسانی یا تأیید مستقل مدرس نیست. پس هیچ الگوی PDF به‌تنهایی، حتی با `--enable-demo-orders`، معامله باز نمی‌کند. برچسب سراسری `video_teacher_semantics_independently_approved=false` با این داده‌ها قابل تبدیل به true نیست. تغییر آن بدون ارجاع واقعی به صوت و تصویر مدرس، ممنوع است.

**منبع و نگهداری:** ۱۳ شاخه اصلی از commit ثابت `b48fb06f...` و اصلاح session19 در شاخه `artin-fxm-teacher-engine-20261110` (با کنترل SHA تمام فایل‌های هسته). اصل و اصلاح‌نشده جدا باقی می‌ماند. صفحات ۱۱، ۱۳، ۱۴، ۱۷ Technical و صفحات ۲ و ۴ FXM پشتوانه بخش‌های PDF هستند. درباره سایر جلسات، فقط ارجاع‌های زمان‌دار موجود در هسته معتبرند و خودشان تأیید مستقل محسوب نمی‌شوند.

## اجرای Windows

در بسته فایل `run_artin_mt5_demo_automatic_observer.cmd` را اجرا کنید. نیازمند Python و کتابخانه MetaTrader5 و ترمینال ePlanet DEMO از قبل متصل است. هیچ ورود مجدد یا توکن لازم نیست. خروجی خصوصی زیر پوشه `private/ARTIN_AUTOMATIC_DEMO_OBSERVER.jsonl` ذخیره می‌شود و شامل وضعیت هر ۱۳ مسیر و علت رد سیگنال است. حساب REAL رد می‌شود.

برای آزمون آفلاین از دستور `python -m unittest -q test_artin_teacher_13route_live_gate test_artin_automatic_demo_integration test_artin_automatic_teacher_engine` استفاده کنید.

**توجه:** کامپایل MQL5، اجرای واقعی ترمینال MT5، سود/زیان و وفاداری نهایی تمام ۲۵ جلسه در این تغییر آزمایش نشده است. آزمون CI شامل شبیه‌ساز رابط بروکر و ورودی آزمایشی است؛ نتیجه معامله واقعی نیست. هدف، اتصال صحیح همه دروازه‌های مدرس در مسیر واقعی تصمیم‌گیری و جلوگیری از اجرای غلط، پیش از هر تجارت آزمایشی است.
