### محدودیت مهم
این سند **حافظهٔ خودکارِ برنامه ChatGPT نیست**. در چت جدید، با داشتن اتصال GitHub می‌توانم با شنیدن عبارت بالا وضعیت را واکشی کنم؛ اگر اتصال نباشد صریح می‌گویم. اینترنت قطع‌شده هم به‌خودی‌خود کار را روی دستگاه یا GitHub ادامه نمی‌دهد؛ تنها اجرای واقعاً زمان‌بندی‌شده یا GitHub Actions می‌تواند مستقل از گفت‌وگو ادامه داشته باشد.

این شاخه به صورت **مستقل از ربات معاملاتی و شاخهٔ main** نگهداری می‌شود. ثبت وضعیت، مجوز تغییر معاملات واقعی یا ادغام کد معاملاتی نیست.

## بازوی اجرایی واقعیِ داخل مخزن (۷ نوامبر ۲۰۲۶)

**فقط فهرست نیست.** این مخزن اکنون دارای فرمان‌دهندهٔ واقعی GitHub Actions است:
- برنامهٔ مجری: `tools-makhzan/executor.py`
- فایل فرمان که دستیار با درخواست صریح کاربر به‌روز می‌کند: `tools-makhzan/requests/current.json`
- گردش‌کار اجرایی: `.github/workflows/tools-makhzan-executor.yml`
- عملیات مجاز:
  - `status`: بررسی زندهٔ وضعیت واقعی نسخه و نتیجهٔ اجرای ابزار در GitHub
  - `build_review`: **اجرای مجدد واقعی** سازندهٔ بستهٔ بازبینی موبایل و ویندوز از شواهد اصلی (نه فقط نمایش فایلِ قدیمی)
  - `source_ingest`: دریافت و آماده‌سازی صوت/تصویر از لینک جدید یوآپلود که کاربر خودش می‌دهد؛ **این عملیات معنی کامل مدرس را تحلیل یا قاعدهٔ معاملات تولید نمی‌کند.**
