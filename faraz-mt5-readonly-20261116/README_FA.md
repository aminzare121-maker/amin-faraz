# پل خواندنی فراز امین — نسخه آزمایشی
این برنامه فقط نوع حساب، موجودی و تعداد معاملات باز را از MT5 می‌خواند. هیچ سفارش خرید، فروش یا بستن معامله‌ای ندارد. فیوز اضطراری هنوز ساخته نشده است.

## راه‌اندازی
۱. MT5 دمو را باز نگه دارید.
۲. پوشه پروژه را از GitHub با Code > Download ZIP دریافت و استخراج کنید.
۳. به پوشه faraz-mt5-readonly-20261116 بروید و start_windows.bat را دوبار کلیک کنید.
۴. راه‌انداز Python 3.12 x64 را بررسی می‌کند؛ اگر نبود با winget برای نصب تلاش می‌کند. اینترنت و احتمالاً تأیید ویندوز لازم است. Python 3.15 حذف نمی‌شود.
۵. پنجره سیاه را باز نگه دارید. صفحه وضعیت در http://127.0.0.1:8765 باز می‌شود.

**وضعیت:** این نسخه روی رایانه کاربر یا MT5 دمو آزمایش نشده است. هیچ تضمینی درباره اتصال وجود ندارد.
