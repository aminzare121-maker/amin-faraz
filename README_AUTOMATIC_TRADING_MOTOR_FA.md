# موتور خودکار آرتین — شناسایی از کندل و اجرای MT5 DEMO

**دستور مالک:** آموزش مدرس باید به موتور معامله‌گری تبدیل شود؛ هیچ قانون اختراعی مجاز نیست. این بسته قابلیت جدید را **روی همان پروژه قبلی** اضافه می‌کند و هیچ فایل اصلی ۱۳مسیره را حذف یا تغییر نمی‌دهد.

## چه چیزی این بار واقعاً ساخته شده است؟

1. `artin_automatic_teacher_recognizer.py`: داده خام کندل بسته‌شده M15 را می‌خواند؛ FVG، بازگشت از ناحیه همراه کندل تردید و اولین کندل اعتماد، و شکست دقیق با کندل بدون سایه را **خودکار** تشخیص می‌دهد. نیازی به فایل `SETUP` یا برچسب‌گذاری دستی معامله نیست. مرجع قواعد: `Technical(1).pdf` صفحات ۱۱، ۱۳، ۱۴ و ۱۷، و ویژگی‌های کندل در هسته موجود.
2. `artin_automatic_trade_cycle.py`: محاسبه حجم با ریسک FXM صفحه ۲، حد ضرر از مرجع ساختاری، حد سود جدول RR صفحه ۴ یا سه TP با جابه‌جایی SL را به تصمیم خودکار متصل می‌کند. شبیه‌ساز داده OHLC، محدودیت ترتیب ناشناخته درون کندل را صریحاً گزارش می‌کند. سناریوی پولی بر اساس **قرارداد/اسپرد/هزینه اعلام‌شده** است، نه هزینه اثبات‌شده بروکر.
3. `artin_mt5_demo_automatic.py`: برای Windows و Python MetaTrader5 ساخته شده است. از ترمینال **از قبل نصب‌شده** فقط با حساب `ePlanet-MT5` و `ACCOUNT_TRADE_MODE_DEMO` کندل می‌گیرد؛ هنگام وجود مدارک لازم امکان ارسال سفارش DEMO، جلوگیری از ارسال دوباره پس از restart، محاسبه حجم با `order_calc_profit` بروکر، سنجش ترتیب SL/TPهای روز و جابه‌جایی استاپ در TP1/TP2 دارد. حالت پیش‌فرض **فقط مشاهده** است. سفارش REAL در کد ممنوع است.

## وضعیت تأیید معنای مدرس؛ مرز غیرقابل حذف

دو مسیر قابل‌اندازه‌گیری از مفاهیم PDF خودکار شده‌اند: `REVERSAL_FVG_DOUBT_CONFIDENCE` و `BREAK_FVG_EXACT_FULLBODY`. این‌ها **زیرمجموعه‌های قابل‌اندازه‌گیری از مبانی مدرس** هستند، نه اثبات اینکه تمام حالات ۱۳مسیر و استثناهای ویدئو را همان‌طور که مدرس قصد داشته پوشش می‌دهند. در آزمون واقعی تاریخی، بازگشت‌ها پیدا شدند و **صفر شکستِ بدون‌سایه با شرط سخت‌گیرانه** دیده شد.

نکته‌های زیر هنوز به‌طور کامل از متن و تصویر مدرس اثبات نشده‌اند و به‌اسم قانون مدرس ارائه نمی‌شوند: اولویت ناحیه در صورت چند FVG هم‌زمان، تفسیر عددی «قدرت»، گزینش کامل آخرین لگ، انتخاب دقیق مرجع استاپ از چند گزینه صفحه ۱۷، نرخ برد واقعیِ مختص همین استراتژی، شرایط استثنا و تصمیم‌های سایر ۱۱ مسیر. فیلتر «نخستین بازگشت» و انتخاب مرز مقابل FVG برای SL **تصمیم‌های محدودکننده/اجرایی پیاده‌سازی** هستند، نه جمله تأییدشده مدرس. تا وقتی این ابهام‌ها رفع نشده‌اند، معامله‌های کاغذی را عملکرد تأییدشده مدرس ننامید.

## آزمون‌های انجام‌شده

- روی فایل موجود کاربر با **۲۳٬۶۴۳ کندل واقعیِ ثبت‌شده ePlanet**: شناسایی خودکار **۲۰۱ کاندیدای غیرمبهم**؛ ۲۱۷ تشخیص بازگشت قبل از رفع ابهام ناحیه و ۸ موقعیت با مرجع چندگانه؛ صفر شکست دقیق بدون‌سایه با شروط فعلی. داده خام از سمت کاربر بود؛ اصالت اتصال بروکر مستقل از رسید قبلی احراز نشده است.
- سناریوی مفروض `winrate=43%` (RR=1.8، حساب $1000، ریسک ۱٪، هزینه و اسپرد صفر فرضی، قرارداد ۱۰۰ دلار به ازای واحد قیمت/لات): ۸۳ معامله کاغذی بسته‌شده و سود سناریویی **۸۳٫۰۵۸ دلار**؛ این **سود قابل معامله یا آزمون واقعی اسپرد نیست**.
- سناریوی فرضی `winrate=50%` با سه هدف صفحه ۴: ۷۵ معامله کاغذی بسته‌شده؛ سود سناریویی **۲۳٫۲۴۶ دلار**. این عدد مبنای تصمیم برای معامله واقعی نیست.
- آزمون واحد تشخیص/مدیریت و آزمون **Mock SDK** اتصال، خواندن، کنترل DEMO، تلاش ارسال یک‌باره و جلوگیری از تکرار بعد از restart: **۳۰ آزمون در هر دو حالت معمولی و `-O`**. آزمون SDK ساختگی است؛ هیچ سفارش واقعی MT5 را اثبات نمی‌کند.
- رگرسیون قبلی: **۱۰۲ آزمون موتور و ۱۴۷ آزمون هسته اصلی**، بعد از جایگزینی نسخه PDFهای اصلی کاربر، موفق بودند. متون و هسته قدیمی تغییر نکردند.

## اجرای Windows

برای نصب از قبل، Python و بسته رسمی `MetaTrader5` باید در Windows در دسترس باشند. فایل‌های `FXM.pdf` و `Technical(1).pdf` اصلی داخل بسته خصوصی حضور دارند؛ ماژول DEMO هش آن‌ها را قبل از هر سفارش بررسی می‌کند. حساب واقعی همیشه رد می‌شود.

برای نمونه بررسی فایل کندل JSONL شخصی (بدون معامله):

```bat
python artin_automatic_trade_cycle.py --bars "private\ARTIN_EPLANET_REAL_23643_M15_OBSERVATIONS_PRIVATE.jsonl" --out "private\RESULT_SCENARIO_43.json" --initial-balance 1000 --reference-balance 1000 --risk-pct 1 --scenario-winrate 43 --scenario-winrate-source SCENARIO_NOT_AUDITED --contract-value 100 --min-lot 0.01 --lot-step 0.01 --fee-per-lot 0 --spread 0
```

برای **مشاهده زنده DEMO بدون ارسال سفارش** (مسیرهای ترمینال و data directory از همان نصب واقعی Codex/Windows گرفته شود):

```bat
python artin_mt5_demo_automatic.py --terminal "C:\PATH\terminal64.exe" --expected-data "C:\Users\...\Terminal\..." --state "private\demo-state.json" --report "private\demo-observer.jsonl"
```

برای فعال‌کردن سفارش‌های DEMO علاوه بر شرط حساب DEMO، *مدارک نرخ برد* با ساختار `fxm_winrate_evidence_v1` و `audited=true`، موجودی مرجع ثابت، افست واقعی روز سرور بروکر، مسیر دقیق ترمینال و پارامترهای اجرایی نیاز است. گزینه `--enable-demo-orders` بدون این موارد خطا می‌دهد. رسید ساختگی یا آمار فرضی را به‌عنوان «audited» نزنید. **هیچ دستور فعال‌سازی سفارش واقعی در این README داده نمی‌شود؛ نخست باید آزمون واقعی DEMO و تأیید انطباق با مدرس ثبت شود.**

## وضعیت و محدودیت

کد و آزمون مستقل روی Linux موجود انجام شده‌اند. **اجرای واقعی روی MetaEditor، Windows کاربر، اتصال جاری ePlanet و نتیجه سفارش DEMO در این نشست هنوز انجام نشده است.** شبیه‌سازی سفارش در Mock معادل معامله واقعی نیست. اعتبارسنجی کامل ویدئوهای ۲۵گانه و تطبیق مستقل همه ۱۳ مسیر هنوز باقی است. این بسته «موتور خودکارِ زیرمجموعه‌های صریح PDF، با ماژول اجرای DEMO» است، نه «موتور تکمیل‌شده و اثبات‌شده همه آموزش‌های آرتین».
