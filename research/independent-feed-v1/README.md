# Issue 23 — آمادگی خوراک مستقل XAUUSD

خروجی فعلی: پژوهش حقوق/مسیر رسمی، adapter آزمایشگاهی مصنوعی، آزمون واقعی آفلاین و برنامه دریافت مرحله‌ای؛ **دریافت و ingestion داده بازار هنوز انجام نشده**.

- [حقوق و منابع](RIGHTS_AND_SOURCES_FA.md)
- [بازاستفاده، برنامه دریافت و مقایسه](PLAN_AND_COMPARISON_FA.md)
- [کد قرارداد](adapter.py)، [آزمون‌ها](test_adapter.py)، [نتایج عددی](results.json)، [لاگ](test-results.txt)

از همین پوشه با Python 3 استاندارد اجرا کنید: `python -B run_checks.py`؛ بدون نصب dependency. این فرمان فقط fixture در حافظه و گزارش محلی تولید می‌کند؛ client شبکه/MT5 ندارد.

نتیجه اجرا در ۲۰۲۶-۱۱-۰۵: **۳۵ PASS، صفر FAIL، صفر ERROR، صفر SKIP**. موارد خارج از دامنه در results.json با NOT EXECUTED جدا مشخص‌اند؛ نبود دانلود/بک‌تست به معنی PASS آن‌ها نیست.

نمونه: ۱۵ دقیقه مصنوعی → یک کندل M15؛ BID O/H/L/C = 100/116/99/101 و ASK = 101/117/100/102. پوشش تقویم مصنوعی ۱۵/۱۵، hash ورودی قبل/بعد برابر؛ spread کندل UNKNOWN. این اعداد هیچ رابطه‌ای با قیمت طلا ندارند.

قرارداد ورودی: bytes JSON immutable، receipt دقیق شامل منبع مصنوعی، mapping، UTC/DST، licence/provenance/hash؛ M1 با open/close/available میلی‌ثانیه epoch و OHLC جدا برای bid/ask به صورت رشته Decimal. هر slot تقویم OPEN/CLOSED/UNKNOWN است. unknown، duplicate حتی یکسان، ترتیب غلط، نقص، تغییر hash، availability آینده و bucket جزئی رد می‌شوند؛ هیچ پرکردن خودکار انجام نمی‌شود. خروجی شامل coverage و flags و hash مبدأ است. بازه fixture حداکثر یک روز؛ ابزار تولیدی/decoder واقعی نیست.

محدودیت: metadata مصنوعی خوداظهاری است و احراز رمزنگاری‌شده منشأ نیست. تقویم بازار، sequence تیک‌های هم‌زمان، حجم، precision واقعی، timeout شبکه و resume اجرایی هنوز پیاده نشده‌اند. DST فقط با offset صریح آزموده شده، نه تقویم تاریخی بروکر. تست‌ها نه مجوز اجرا می‌دهند نه دقت پیش‌بینی مالی را ثابت می‌کنند. gate بازاستفاده‌شده عمداً fit/trade/real-data را بسته نگه می‌دارد.

برای مرحله بعد باید بازبینی، دامنه نمونه واقعی و سقف هزینه ثبت شوند. main، برنامه نصب‌شده، کابین، حساب و معامله در این بسته تغییر نمی‌کنند.
