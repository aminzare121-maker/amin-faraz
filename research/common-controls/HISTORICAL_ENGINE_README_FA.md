# موتور پژوهشی تاریخی فراز — نمونه اجرایی مستقل، نه ربات معامله‌گر

**هدف:** برطرف کردن محدودیت «فقط داده مصنوعی / ۲۴۰ کندل پیوسته» در یک مسیر جدید آزمایشگاهی، *بدون دست‌کاری موتور اصلی*. موتور از کندل‌های واقعی موجود می‌تواند استفاده کند، بازه‌های پیوسته را جدا می‌کند، فقط کندل‌های بسته‌شده را به تابع سیگنال می‌دهد، و هر نتیجه را از نظر مفروضات و عدم‌قطعیت برچسب می‌زند.

## وضعیت دقیق و مواردی که هنوز انجام نشده

- این بسته شامل `historical_engine.py` (موتور replay با `Decimal`)، `historical_runner.py` (خواندن فقط‌خواندنی Eplanet از **loader موجود**)، و آزمون‌های مستقل است.
- **الگوریتم معاملاتی نهایی فراز ساخته یا تأیید نشده.** سه سیگنال فعلی فقط کنترل: SMA(5,20) ثابت و دو baseline خرید/فروش ثابت بعد از ۲۱ کندل بسته‌شده. برای ارزیابی شش روش قبلی فراز، Codex باید تابع `plan` اصلی هر candidate را پس از ممیزی رابطش به `simulate` وصل کند، نه با جایگزین‌کردن این baselineها.
- زمان Eplanet فقط در بازه‌ای که شواهد صریح دارد با `--offset-seconds` **مشروط** تفسیر می‌شود. ۲۶۰ وقفه سال و نگاشت سراسری UTC همچنان UNKNOWN هستند. مسیر داده خصوصی ویندوز در `offline_evidence` ازقبل ثبت شده؛ نسخه جدید چیزی دانلود/کپی نمی‌کند.
- اسپرد، لغزش و کمیسیون این runner **فرضی** هستند، حتی اگر برای تست مقدار صریح داده شوند؛ Bid/Ask داخل کندل از اختلاف ثابت تقریب زده می‌شود؛ مسیر Tick تأیید نشده. سود و افت سرمایه خروجی صرفاً **سناریویی** و اکتشافی‌اند؛ نه بک‌تست مالی معتبر، نه اعتبار انتخاب استراتژی و نه تضمین سود.
- هزینه Rollover ناشناخته در معاملات عبورکننده از مرز روز UTC باعث خروجی unresolved می‌شود؛ UTC روزانه جایگزین ساعت واقعی rollover بروکر نیست. بازه‌های داخل‌روز نیز اگر سند ساعت rollover ندارند نباید «سوآپ صفرِ تأییدشده» بنامند.
- هزینه و مجوز جدید، نصب، ارسال سفارش، دستکاری MT5 یا تغییرات main لازم/مجاز نیست. از اجرای برنامه اصلی خبری نیست.

## اجرای آزمون‌های مستقل

```powershell
cd research\common-controls
python -X utf8 -m unittest test_historical_engine test_historical_runner -v
```

## اجرای محلی فقط به‌عنوان تشخیص اکتشافی روی داده Eplanet موجود

**فقط روی دستگاهی اجرا شود که `offline_evidence.load_existing` و بسته‌های خصوصی مجاز واقعاً در دسترس‌اند.** این دستور هیچ شبکه یا سفارش معاملاتی ندارد.

```powershell
python -X utf8 historical_runner.py --start 2026-11-04T00:00:00Z --end 2026-11-04T22:00:00Z --offset-seconds -7200 --assumed-spread 0.3 --assumed-slippage 0.1 --assumed-roundtrip-commission 0 --output "$env:TEMP\faraz_real_diagnostic_local.json"
```

این فقط **نمونه دستور با فرض‌های آشکار** است، نه ادعای معتبربودن ساعت تاریخی یا هزینه این بازه. اگر مسیر private یا اعتبار داده مجهول بود، اجرا نشود و علت ثبت شود. فایل JSON تولیدشده در GitHub بارگذاری نشود.

## معیار پذیرش واقعی مرحله بعد

۱. کدکس این بسته را با نسخه محلی `amin_mt5` و داده خام بدون تغییر اجرا کند و تعداد کندل و نتایج را فقط با برچسب `EXPLORATORY_ONLY` گزارش دهد. نبود سیگنال به معنی سود صفر نیست؛ تعداد معامله نیز گزارش شود.
۲. شش candidate اصلی فعلی را با adapter تست‌شده و signal boundary علی (causal) متصل کند و هر اصلاح را جدا تست کند؛ تغییر استراتژی/پارامتر بعد از مشاهده نتیجه ممنوع.
۳. برای خروجی **معتبر**، مدرک زمان/سشن/قیمت Bid-Ask و هزینه تاریخی یا دامنه مستند، حاکمیت Holdout و کنترل هزینه ضروری است. اگر نداشتیم، از گزارش عدد فرضی به‌عنوان «جواب نهایی» استفاده نکنیم.
۴. هر نتیجه مشروط/واقعی و کد/آزمون در Draft PR جدا یا PR30 (بدون Merge) مستند شود. بازتولید و آزمون محلی Windows هنوز انجام نشده است.
