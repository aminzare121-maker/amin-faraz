# تحویل برای ادامه فردا — فراز / بازیابی داده‌های M15 از M5 (۶ نوامبر ۲۰۲۶)

## هدف
مقایسه کندل‌های ۱۵ دقیقه‌ایِ غایب در تاریخچه خصوصی XAUUSD.st بروکر Eplanet با سه کندل ۵ دقیقه‌ای همان نماد و همان حساب؛ **صرفاً پژوهشی**، بدون معامله.

## منبع داده و وضعیت فعلی
- مخزن اصلی پژوهش: aminzare121-maker/amin-faraz، Draft PR #32
- گزارش مرجع: https://github.com/aminzare121-maker/amin-faraz/pull/32#issuecomment-6664081463
- دستور کنترل M5 قبلی: https://github.com/aminzare121-maker/amin-faraz/pull/32#issuecomment-6664133250
- ۲۳٬۶۴۳ ردیف M15 ثبت‌شده؛ ۲۶۰ فاصله زمانی و ۱۱٬۳۹۷ جایگاه M15 غایب در دوره اسمی یک‌ساله.
- ۱۹۹ فاصله یک‌ساعته، ۴۸ فاصله ۴۹ساعته، ۱۳ فاصله دیگر؛ هیچ‌کدام اثبات حذف عمدی نیست.
- خام M15 و M5 مربوط به حساب کاربر در GitHub قرار نگرفته؛ فایل‌های واقعی M5 و اجرای حقیقی MT5 هنوز توسط ChatGPT دیده/تأیید نشده‌اند.
- اولویت بررسی: gap #18 = 2025-11-28 11:00؛ gap #142 = 2026-05-25 22:00 (برچسب‌های خام فایل، نه زمان UTC قطعی).

## فایل‌های موجود در این شاخه
1. FARAZ_M5_ReadOnly_Export.mq5 — دریافت فقط‌خواندنی کندل‌های دو بازه هدف از MT5؛ هیچ ارسال سفارش ندارد؛ کامپایل MQL5 در این محیط تأیید نشده.
2. faraz_m5_audit.py — تطبیق کندل‌ها و بازسازی پژوهشی مشروط؛ نیازمند Python 3 و CSVهای واقعی محلی.
3. RUN_AUDIT_WINDOWS.bat — اجرای تحلیل آفلاین روی Windows.
4. test_faraz_m5_audit.py و synthetic_test_results.txt — دو تست موفق صرفاً با داده ساختگی.
5. README_فارسی.txt — راهنمای گام‌به‌گام استفاده، بدون Codex.

## ادامه کار
1. ابتدا کل فایل‌ها و راهنما را بخوان. سورس اصلی MT5، تنظیمات بروکر، PR32 و main را تغییر نده.
2. وقتی مالک به لپ‌تاپ دسترسی داشت، با تأیید او اسکریپت فقط‌خواندنی را روی DEMO Eplanet در MT5 کامپایل/اجرا کند و خطاها را بررسی کند.
3. گزارش FARAZ_probe_export_log.txt را تحلیل کن. وجود «M5_exact=3/3» فقط نشان‌دهنده پیدا شدن سه M5 در تاریخچه ترمینال است؛ بازیابی قطعی M15 نیست.
4. حداقل ۱۰۰ کندل M15 موجود را با M5 همان feed کنترل کن؛ ساعت‌مبنا/DST و حقوق استفاده از داده را روشن نگه دار؛ نتیجه‌های ناقص را UNKNOWN اعلام کن.
5. هیچ داده قیمت خام یا اطلاعات شخصی حساب را در GitHub منتشر نکن؛ اگر تحلیل تمام‌سال خواسته شد، بر مبنای مجوز و شواهد جدید جلو برو.
6. هیچ سفارش دمو/واقعی، تغییر موتور اصلی، Merge یا نصب خودکار انجام نشود.
