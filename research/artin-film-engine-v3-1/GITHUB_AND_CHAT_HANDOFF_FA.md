## فیلمی که در گفتگو آپلود می‌شود

اتصال GitHub به فایل‌های ضمیمه گفتگو **دسترسی خودکار ندارد**. اگر فیلم آپلود شود، دستیار می‌تواند هنگام همین گفتگو با مسیر فایل قابل‌دسترسی در محیط اجرا، برنامه مخزن را روی فیلم به کار ببرد و خروجی را با عنوان *آزمون واقعی* یا *نیازمند مدل* گزارش کند. کد مخزن به‌خودی‌خود سرویس اجرای دائمی یا اتصال مستقیم به حافظه گوشی نیست.

برای برش و اسکن فریم:

```bash
python3 -B artin_film_pipeline.py prepare --video "/path/to/video.mp4" --out "/path/to/PRIVATE_out" --workers 4 --frames-per-chunk 3
```

تطبیق فایل‌های `manifest.json` و `chunk_order_verified.json` با ۱۸ شماره برای فیلم ۹۰ دقیقه‌ای ضروری است. تشخیص گفتار فارسی و تحلیل نمودارها نیازمند نصب مستقل مدل‌های `faster-whisper` و Ollama تصویری است و در مخزن GitHub خودکار نصب یا اجرا نمی‌شود.

گزارش‌های غیرحساس ممکن است در شاخه گزارش خصوصی ثبت شوند؛ **فیلم، صدا، رونوشت و تصاویر شخصی به شکل پیش‌فرض در GitHub بارگذاری نمی‌شوند**. آپلود اصل فیلم به مخزن به محدودیت GitHub و تصمیم مجزا برای محل نگهداری امن بستگی دارد. فیلم‌های بیش از ۱۰۰ مگابایت با Git معمولی پذیرفته نمی‌شوند.

## مسئولیت
مدل نباید بدون شاهد دقیق دقیقه/ثانیه و آزمون مثال‌های واقعی ادعا کند روش مدرس را بازسازی کرده است. هیچ خرید/فروش یا تغییر موتور اصلی آرتین با این بسته مجاز نیست.

## مسیر ویندوز
