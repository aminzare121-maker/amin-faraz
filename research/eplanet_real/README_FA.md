# Eplanet REAL — خواندن تاریخچه از MT5 فقط برای پژوهش

**وضعیت:** ابزار در branch پژوهشی نوشته شده است؛ تا این لحظه **روی ویندوز مالک اجرا نشده**. اتصال GitHub به معنی کنترل مستقیم ترمینال/اپ Codex نیست.

## مأموریت Codex Windows (با تأیید تازه مالک)
کاربر صریحاً خواست داده‌ها از **حساب واقعی Eplanet که هم‌اکنون در ویندوز متصل است** دریافت شود، نه حساب دمو. این مجوز **تنها خواندن تاریخچه و مشخصات نماد XAUUSD.st** است، نه معامله یا تغییر تنظیمات حساب.

1. قبل از اجرا سورس `export_readonly.py` را از این branch مرور کن و وجود هرگونه تابع ثبت/ویرایش/لغو سفارش، انتشار داده، تماس با سرور ثالث یا دسترسی به اطلاعات حساس حساب را بررسی کن. فقط از ترمینال از قبل باز و متصل استفاده کن. هیچ credential/شماره حساب ثبت یا ارسال نشود.
2. در نشست ویندوز، مسیر Python دارای ماژول `MetaTrader5` را بررسی کن. اگر نصب نیاز است، قبل از نصب اجازه بگیر؛ بسته/نسخه را ثبت کن.
3. **اجرای مرحله نمونه:** `python research/eplanet_real/export_readonly.py --days 7 --tick-minutes 10 --output PRIVATE_EPLANET_HISTORY`. در صورت نبود اطلاعات به دلیل `Max bars in chart`، تنظیمات را بدون اجازه دستکاری نکن؛ گزارش مانع بده.
4. اگر نمونه معتبر بود و بار غیرمتعارف نداشت، `--days 365 --tick-minutes 30` را اجرا کن. Tick فقط یک نمونه ۳۰ دقیقه‌ای است، **هیچ دانلود یک‌ساله Tick مجاز یا انجام‌شده تلقی نشود**.
5. گزارش `qa_report.json` را از نظر ردیف M15، نخستین و آخرین کندل، timestamp UTC، duplicate، invalid OHLC، gap (با تفکیک تعطیلی) و نمونه Bid/Ask بررسی کن. `UTC` خروجی کتابخانه نباید دوباره با offset سرور جمع/تفریق شود. برای اختلاف EET/EEST و DST نیویورک آزمایش جدا انجام بده.
6. **فایل‌های خام CSV، اطلاعات حساب، server id کامل یا هر مقدار محرمانه را به GitHub نفرست**. فقط خلاصه پاک‌سازی‌شده QA، پوشش، SHA، آزمون و فایل/فرمان بدون اطلاعات حساس را در Issue #9 ثبت کن. داده‌ها صرفاً برای پژوهش خصوصی، نه بازتوزیع.
7. مقایسه با Dukascopy را بعداً فقط روی داده‌ای که حق پژوهش دارد، در روز/ساعت هم‌پوشان و با درنظرگرفتن Bid/Ask، زمان، سشن و اختلاف منبع انجام بده. قبل از بک‌تست، هزینه اسپرد و سوآپ نامشخص UNKNOWN باقی بماند.
8. هر خطا را `FAIL/UNKNOWN` ثبت کن، موفقیت ساختگی اعلام نکن. اگر account trade_mode REAL نیست، Eplanet server نامطابق است یا connection وجود ندارد، **متوقف شو و حساب را عوض یا لاگین نکن**.
9. دستورات قبلی فراز #19، #23، کابین #16 و تقویم #24/PR #26 متوقف یا فراموش نشود؛ پس از این نمونه، وضعیت هر جریان کار را حفظ کن.

**فقط خواندن.** هیچ `order_send`، `order_check`، معامله، EA، اسکریپت معامله‌گر، تغییر ربات، Merge، نصب روی حساب یا انتشار عمومی انجام نشود.
