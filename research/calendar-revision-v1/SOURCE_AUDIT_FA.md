# ممیزی منابع — ۵ نوامبر ۲۰۲۶

اعتبار ناشر با کامل‌بودن داده/سرعت/حقوق برابر نیست. latency و نرخ خطای زنده در این مرحله اندازه‌گیری نشده؛ همه SLAها UNKNOWN هستند. raw، hash، timestamp انتشار/دریافت/بررسی و بازنگری باید مستقل حفظ شوند. تکرار خبر یک ناشر در چند رسانه شاهد مستقل نیست. consensus بازار، actual رسمی و تحلیل سه نوع داده جدا هستند.

پیشنهاد منابع مکمل: BEA برای GDP/PCE، Treasury برای نرخ‌ها، مرکز آمار و بانک مرکزی برای تعاریف رسمی ایران؛ قبل از اتصال باید endpoint رسمی، حقوق، schema، latency و ثبت revisions تأیید شوند. صفحه signup API BEA در این بررسی خطای دسترسی داد؛ تأیید یا اتصال موفق ادعا نمی‌شود. consensus پیش از خبر احتمالاً محصول جدا با مجوز/هزینه جداست؛ از عدد forecast ساختگی استفاده نشود.

برای ایران: تورم جهانی→انتظارات سیاست/بازده واقعی→دلار/اونس یک فرضیه مشروط است. اونس و نرخ آزاد ریال، حباب/کارمزد صندوق و محدودیت بازار داخلی کانال‌های جدا می‌خواهند. نرخ رسمی جای آزاد، شاخص بورس جای NAV صندوق، یا خبر تحریم جای تغییر قطعی قیمت استفاده نشود. داده فعلی برای قاعده تجربی تأییدشده کافی نیست؛ خروجی این مسیر UNKNOWN می‌ماند.
