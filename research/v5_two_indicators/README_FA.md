# دو اندیکاتور روی M15 — شاخه پژوهشی V5

**وضعیت:** اتصال‌دهنده و آزمون‌های فنی ساخته شده‌اند، اما نام/فرمول دقیق دو اندیکاتور داخل تصاویرِ آخرین پیام در ابزارهای این نشست قابل خواندن نیست. هیچ اندیکاتوری به حدس جانشین نشده است و **سودآوری دو اندیکاتور هنوز آزمایش نشده است**.

## هدف
ارزیابی نقش دو اندیکاتور در تشخیص زمان ورود / ادامه روند / شکست ناموفق، در کنار موتور پژوهشی M15 و اسکلپ انتخابی؛ بدون حذف خودکار سیگنال یا تغییر حجم و حد ضرر. این بخش موتور نهایی یا کد اصلی V5 نیست.

## داده لازم
CSV با ستون‌های:
- bar_open_utc : زمان شروع کندل M15 به UTC
- indicator_1, indicator_2 : سیگنال همان کندل بسته‌شده، اعداد 1 (صعودی)، -1 (نزولی)، 0 (خنثی)
- indicator_1_ready_utc, indicator_2_ready_utc : زمان واقعی قابل استفاده بودن سیگنال؛ حداقل ۱۵ دقیقه پس از آغاز کندل.

برای اندیکاتورهایی که بعداً سیگنال‌های قدیمی را تغییر می‌دهند (repaint)، **خروجی تاریخی معمولی کافی نیست**؛ باید نسخه ثبت‌شده در زمان واقعی در دسترس باشد.

## اجرا
پوشه فعلی را research/v5_two_indicators قرار بدهید:

```bash
python -m unittest -v test_indicator_pair_shadow.py
python indicator_pair_shadow.py --trades V5_WALKFORWARD_TRADES.csv --indicators two_indicators_exact.csv --out result
```
