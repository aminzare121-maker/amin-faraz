# واسط قیمت MT5 اندروید ـ نسخه آزمایشی
هدف: خواندن محلی جفت Bid/Ask قابل مشاهده XAUUSD.st فقط وقتی کاربر ثبت را روشن کرده، قفل صفحه باز است و پنجره فعال متعلق به بسته رسمی net.metaquotes.metatrader5 است. نیازمند مجوز Accessibility با انتخاب دستی. هیچ کلیک، ورود حساب، اتصال شبکه، سفارش، دسترسی به فایل‌های خصوصی MT5 یا دور زدن محدودیت اندروید انجام نمی‌شود.
ساختار UI واقعی MT5 هنوز بررسی نشده است. اگر نماد و قیمت‌ها با برچسب Bid/Ask یا شناسه‌های شناخته‌شده در یک ردیف قابل مشاهده نباشند، برنامه هیچ قیمت حدسی ثبت نمی‌کند. برای ثبت، صفحه Quotes/قیمت‌ها را باز نگه دارید. خاموش شدن یا قفل صفحه ثبت را متوقف می‌کند. با توقف یا خروجی، داده فقط داخل گوشی ذخیره/صادر می‌شود. زمان ثبت دستگاه است؛ نمونه‌برداری ۲۵۰ میلی‌ثانیه‌ای همه تغییرات قیمت را تضمین نمی‌کند؛ ثبت مجدد قیمت بدون تغییر پس از ۵ ثانیه صرفاً مشاهده UI است، نه تیک. تاریخچه یک‌ساله یا دسترسی مستقیم سرور بروکر از این راه حاصل نمی‌شود.
خروجی CSV را تنها با انتخاب کاربر به محل موردنظر منتقل کنید. GitHub عمومی محل انتشار داده خام نیست. CI فقط کد و APK آزمایشی می‌سازد؛ آزمون روی دستگاه واقعی مالک ضروری است.
