# آرتین — موتور اتصال مفهومی ۱۸ بخشِ فیلم آموزشی

## وضعیت واقعی

این نسخه یک **برنامه واقعی و قابل اجرا** برای برش فیلم ۹۰ دقیقه‌ای، پردازش بخش‌ها، ساخت خط زمانی یکپارچه، ربط‌دادن **احتمالی** سؤال‌وجواب‌ها و اصلاحات قوانین، ساخت زیرنویس، و ساخت دوباره نسخه‌ای از **همان ویدئوی اصلی** با ۱۸ فصل است. تمام برچسب‌های قاعده، سؤال و اصلاح که یک مدل تولید کند، تا بازبینی صوت/تصویر و مثال‌های کلاس فقط **نامزد بررسی** هستند؛ این خروجی به موتور معامله واقعی متصل نیست.

## اجزای ورودی

- فیلم آموزشی اصلی (با صدا و تصویر)؛ ۹۰ دقیقه → ۱۸ قطعه اصلی پنج‌دقیقه‌ای.
- FFmpeg و FFprobe روی ویندوز یا لینوکس.
- Python 3.10 یا جدیدتر.
- برای تبدیل خودکار صوت فارسی به متن: `faster-whisper` و یک **مدل از قبل نصب‌شده و محلی**. نصب اختیاری کتابخانه: `pip install faster-whisper`. این برنامه هیچ مدل حجیمی را پنهانی دانلود نمی‌کند.
- برای تحلیل معنایی: **Ollama محلی** و مدلی که فارسی را بفهمد؛ برای تحلیل تصاویر از مدل **دارای قابلیت vision** استفاده شود. این برنامه فقط به `http://127.0.0.1:11434` متصل می‌شود؛ هیچ ویدئو یا رونوشت را به سرور خارجی آپلود نمی‌کند. نصب و تهیه مدل بر عهده کاربر است.

## اجرای خودکار در ویندوز

فیلم را روی `RUN_ARTIN_18_WINDOWS.bat` بکشید یا پس از اجرای فایل مسیر ویدئو را وارد کنید. برنامه مسیر پوشه مدل Whisper و نام مدل Ollama را می‌پرسد. سپس مراحل زیر را انجام می‌دهد. **این فایل BAT هنوز روی ویندوز صاحب فایل‌ها اجرا نشده است.**

## مراحل قابل اجرای مستقل

از داخل پوشه برنامه، برای نمونه:

```powershell
python artin_film_pipeline.py prepare --video "D:\Clips\session21.mp4" --out "PRIVATE_ARTIN_CLASSROOM_RESULT" --workers 3 --frames-per-chunk 3
python artin_film_pipeline.py transcribe --out "PRIVATE_ARTIN_CLASSROOM_RESULT" --model-path "D:\Models\faster-whisper-fa" --workers 1
python artin_film_pipeline.py analyze --out "PRIVATE_ARTIN_CLASSROOM_RESULT" --model "MY_LOCAL_VISION_MODEL" --workers 2 --with-frames
python artin_film_pipeline.py merge --out "PRIVATE_ARTIN_CLASSROOM_RESULT"
python artin_film_pipeline.py reconcile --out "PRIVATE_ARTIN_CLASSROOM_RESULT" --model "MY_LOCAL_VISION_MODEL"
python artin_film_pipeline.py remux --out "PRIVATE_ARTIN_CLASSROOM_RESULT" --video-output "PRIVATE_ARTIN_CLASSROOM_RESULT\original_with_18_chapters.mp4"
```

برای اجرای همه مراحل در یک فرمان (پس از نصب مدل‌ها):

```powershell
python artin_film_pipeline.py all --video "D:\Clips\session21.mp4" --out "PRIVATE_ARTIN_CLASSROOM_RESULT" --asr-model "D:\Models\faster-whisper-fa" --ollama-model "MY_LOCAL_VISION_MODEL" --workers 2 --with-frames
```

**چرا تعداد پردازش هم‌زمان لزوماً ۱۸ نیست؟** برنامه ۱۸ وظیفه را آماده می‌کند، اما تعداد وظایف سنگین فعال در هر لحظه بر اساس رم و سرعت پردازنده قابل تنظیم است. اجرای ۱۸ مدل گفتار/تصویر روی یک لپ‌تاپ معمولی ممکن است حافظه را تمام کند؛ تنظیم دو پردازش برای شروع محافظه‌کارانه است.

## نحوه اتصال ۱۸ بخش

- قطعه `۱` دقیقه ۰ تا ۵؛ قطعه `۲` دقیقه ۵ تا ۱۰؛ ...؛ قطعه `۱۸` دقیقه ۸۵ تا ۹۰.
- برای جلوگیری از قطع سؤال/پاسخ، اطراف مرزهای قطعه ۱۲ ثانیه هم‌پوشانی وجود دارد.
- هر جمله، زمان مطلق در ویدئوی اصلی و شناسه دارد؛ قسمت‌های تکراری در هم‌پوشانی حذف می‌شوند.
- استخراج قواعد **صرفاً کاندید** و با نقل‌قول قابل ردیابی از رونوشت است. نقل‌قول اختراعی مدل رد می‌شود.
- «سؤال محتمل در قطعه ۱ → جواب محتمل در قطعه ۲» در گراف ثبت می‌شود، اما **گویندهٔ پاسخ به‌عنوان مدرس تأیید نمی‌شود**.
- «توضیح قبلی قانون → اصلاح احتمالی در قطعه ۱۸» ثبت می‌شود؛ اصلاح بدون اعتبارسنجی فیلم، قانون اصلی آرتین را تغییر نمی‌دهد.
- در حالت `--with-frames` برای هر نامزد استخراج‌شده، تصویری از همان زمان در **ویدئوی اصلی** ذخیره می‌شود؛ فقط شاهد برای بازبینی است، نه اثبات تفسیر مدل.
- مدل می‌تواند یک گذر دوم روی **خلاصه نامزدهای همه ۱۸ بخش** انجام دهد تا ارتباط‌های غیرهم‌نام را پیشنهاد دهد؛ این کار جای مشاهده کامل صدا و تصویر را نمی‌گیرد.

## خروجی‌ها

| فایل | کاربرد |
|---|---|
| `manifest.json` | ۱۸ قطعه و شناسه/اثر انگشت منبع |
| `transcripts/part_XX.json` | گفتارِ تشخیص‌داده‌شده با زمان قطعی در فیلم |
| `analyses/part_XX.json` | نامزد سؤال/جواب/قانون و نقل‌قول با منبع |
| `unified_timeline.json` | بازسازی توالی تمام جمله‌ها و نامزدهای قواعد |
| `rule_candidate_graph.json` | ارتباط قانون، سؤال‌وجواب و اصلاحات احتمالی |
| `artin_engine_handoff.json` | بسته نامزدِ قابل ردیابی برای برنامه‌نویسی پس از تأیید مدرس؛ غیرقابل اجرا |
| `global_connection_suggestions.json` | اتصال پیشنهادی سراسری در گذر دوم مدل |
| `unified_subtitles.vtt` | زیرنویس یکپارچه با زمان فیلم اصلی |
| `audit_report.json` | نقص‌ها، بخش‌های پردازش‌نشده و وضعیت اعتبار |
| `original_with_18_chapters.mp4` | **همان فیلم اصلی** بدون دوبرابرشدن قسمت‌های هم‌پوشان، با ۱۸ فصل قابل مراجعه |

نکته: فیلم خروجی به خودی خود قوانین را داخل تصویر نمی‌نویسد. اطلاعات قابل جست‌وجو و ارتباط قوانین در فایل‌های جانبی JSON/VTT نگهداری می‌شود. این‌گونه اصل تصویر و صدای فیلم دستکاری معنایی نمی‌شود.

## حدود صداقت و ایمنی

**این محیط اکنون مدل محلی تشخیص گفتار فارسی، مدل Ollama نصب‌شده و اصل فیلم‌های مدرس را ندارد.** بنابراین تست قابل انجام فعلی، آزمایش فنی FFmpeg و ادغام روی گفت‌وگوهای مصنوعی است، نه شاهد فهم واقعی ۹۰ دقیقه درس. پردازش و بازبینی ویدئوهای کاربر، نمونه مثبت و منفی طبق مدرس، و سپس پیاده‌سازی منطق کندل خام و مدیریت SL/TP هنوز باقی است.

حالت `artin_rule_ready` و `teacher_rules_approved` عمداً تا زمان تأیید مستقل **false/0** می‌مانند؛ حتی خروجی کامل یک مدل زبانی مجوز معامله نیست.

برای تست مستقل:

```powershell
python -m unittest -v test_artin_film_pipeline
```

برای تست ۱۸ قطعه با فیلم **مصنوعی ۹۰ دقیقه‌ای** و گفت‌وگوهای کاملاً ساختگی:

```powershell
python demo_90min_synthetic.py --video "D:\Temp\fake_90min.mp4" --out "PRIVATE_ARTIN_SYNTHETIC_DEMO"
```
