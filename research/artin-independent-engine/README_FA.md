# آرتین مستقل — پژوهش رفتاری۰٫۶

کار همچنان در حال تکمیل است؛ موتور خودکار کامل یا سودآوری تأییدشده تحویل نشده است. توضیح تغییرها و حدود در docs/S22_V06_WORKING_FA.md است.

run_raw.py انتخاب مسیر ثابت را با --rule می‌پذیرد؛ حالت همهٔ شاخه‌ها تشخیص پژوهشی است. مثال فروش جلسه۲۲ مدل شرطی جدا دارد. مرجع بدنه/سایه در آن هنوز فرضیه است و انتخاب نامعلوم، REVIEW می‌دهد. فرضیهٔ سازگار با یک مثال، فرمول عمومی مدرس نیست.

بخش‌هایی از مکث مخالف‌رنگ خرید جلسه۲۱ اکنون از خام استخراج می‌شوند: نقش مکث قبلی، سایهٔ مرجع، کلوز بعدی و تازگی زنجیره پس از run زمان‌دار. تشخیص خودکار قوی‌بودن run، محل و تمام الگوهای مکث کامل نیست. اندازه‌گیری نسبی سکانس فقط با شروع منبع‌دار و دادهٔ پیوسته انجام می‌شود؛ هیچ برچسب قدرتی خودکار از آن ساخته نشده است. ناحیهٔ یک‌سوم با دو endpoint منتخب محاسبه می‌شود؛ نقطهٔ حد انتخاب نمی‌شود.

۱۳۶آزمون نرم‌افزاری موفق:۱۱۱قبلی+۲۵جدید. اجرای python -B -m unittest discover -q آزمون نرم‌افزار است. مثال run_engine.py --demo --output DEMO_RESULT.json کاملاً مصنوعی است؛۱۳case کدی به‌معنی۱۳روش مستقل مدرس یا۱۳معاملهٔ واقعی نیست.

فقطstdlib و ماژول‌های همین بسته؛ بدون شبکه، MT5، اتصال موتورهای قبلی و سفارش. هیچ بازآزمایی ماهانه در۰٫۶انجام نشد. traceهای PRIVATE،رسانه،متن خام و داده‌های اصلی خصوصی‌اند.
