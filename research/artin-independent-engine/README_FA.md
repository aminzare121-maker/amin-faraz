# آرتین مستقل — اصلاحات۰٫۴

نسخهٔ پژوهشی در حال تکمیل است؛ موتور خودکار کامل یا سودآوری تأییدشده نیست. اصلاح واقعی R1..R5 وC4، حافظهٔ مرجعFVG و رفتار عبور تازه اضافه شد. شرح کامل و محدودیت‌های باقی‌مانده در docs/REPAIR_V04_FA.md است.

۸۷آزمون نرم‌افزاری موفق؛ نمونهٔ synthetic با دادهٔ بازار اشتباه نشود. برای آزمون‌های نرم‌افزاری از `python -B -m unittest discover -q` و برای نمونه از `python -B run_engine.py --demo --output DEMO_RESULT.json` استفاده می‌شود. هیچ برنامه‌ای نصب نمی‌شود.

run_raw.py برای ورودی خصوصی CSV، زمان‌بندی، context و execution صریح است؛ از OHLC به‌تنهایی fill/هزینه/جهت اقتصادی ساخته نمی‌شود. ورودی مجازِ فاقد مشخصات اجرا با EXECUTION_BLOCKED گزارش می‌شود. ردگیری PRIVATE شامل قیمت و منشأ ورودی‌هاست و نباید منتشر شود.

موتور از تمام موتورهای قبلی جداست؛ فقطstdlib و ماژول‌های همین بسته را importمی‌کند. بدون شبکه، MT5، سفارش و نصب. نسخهٔ۰٫۳وگزارش ماهانه‌اش حفظ شده‌اند؛ در۰٫۴آزمون ماهانه تکرار نشد.
