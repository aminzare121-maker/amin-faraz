# همراه امین — نمونه مستقل کابین v2

مرحله A/B/C/D از Issue16؛ نمونه مرورگری آفلاین برای بررسی طراحی، نه نسخه Windows/Android قابل نصب و نه موتور معامله. مبنا: ناوبری Workspace و تقسیم صفحات موجود ۰٫۴٫۳٫۷؛ منطق اتصال/فرمان آن عمداً وارد این آزمایشگاه نشده است. هیچ تغییر در نصب یا main انجام نشده است.

## اجرا

بدون نصب dependency، با Node موجود:

```text
node --test tests/model.test.cjs
node serve.cjs
```

سپس http://127.0.0.1:8769 را باز کنید. سرور فقط فایل‌های همین نمونه را روی loopback عرضه می‌کند؛ با Ctrl+C متوقف می‌شود. index.html را نیز می‌توان مستقیم در مرورگر باز کرد. هیچ CDN، font خارجی، broker SDK، fetch یا WebSocket وجود ندارد؛ CSP اتصال و فرم شبکه را منع می‌کند. server ابزار پیش‌نمایش است نه API موتور.

## دامنه

۸ صفحه: نمای اصلی، جایگاه MT5، سفارش‌های نمونه، ریسک، AI، آزمایشگاه، موبایل، ابزارهای شخصی. مستقیم/بعدی/قبلی/کلید چپ‌راست؛ در RTL کلید چپ صفحه بعد و swipe راست صفحه بعد است. swipe روی نمودار و کنترل‌ها ناوبری ایجاد نمی‌کند. کاهش حرکت دستی و سیستم رعایت می‌شود. ابزارهای شخصی صریحاً «بعداً» هستند.

داده حساب UNKNOWN و ارقام حساب — هستند. نمودار مصنوعی، نه تصویر بازار یا پنجره MT5. هزینه‌های مثال ۱ و۰٫۰۱ lot فرضی‌اند و نرخ Eplanet نیستند. لوگوی مصوب و فایل faraz_ui_concepts.html دیده نشده‌اند؛ بر اساس مشخصات متنی الحاقیه طراحی مستقل انجام شد. لوگوی حدسی وارد نشده است.

درخواست‌های mock فقط ارزیابی محلی می‌شوند و همیشه ordersSent=0 دارند. حتی عبور fixture آزمون واحد، اختیار اجرا نیست. policy سه‌درصدی fixture صرفاً برای آزمون حد است؛ تعارض مالک۳٪/release۶٪ حل نشده و هیچ تنظیم محصول تغییر نکرده است. ژورنال نمونه در حافظه است و با refresh پاک می‌شود؛ دوام production در معماری پیشنهاد شده، نه پیاده‌سازی فعلی.

## محدودیت تحویل

کابین نهایی نیست. هیچ build/install اپ اصلی، اتصال بروکر، دانلود تاریخچه، آموزش، بک‌تست یا معامله انجام نمی‌شود. برای اعمال هر صفحه، تأیید جداگانه مالک و آزمون integration لازم است. آزمون touch روی دستگاه Android واقعی هنوز جدا از شبیه‌سازی منطق gesture است. وضعیت تست واقعی و تصاویر در VALIDATION.md ثبت می‌شود.
