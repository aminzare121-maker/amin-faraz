# فراز — آداپتور تشخیصی تاریخچه XAUUSD M15

**وضعیت ۲۰۲۶-۱۱-۰۵: کد پژوهشی و آزمون مستقل آماده؛ روی داده Eplanet لپ‌تاپ هنوز اجرا نشده است.**

## هدف
موتور فعلی selector در PR30 حداقل ۲۴۰ کندل پیوسته می‌خواهد و ورودی تاریخی واقعی را نمی‌پذیرد. این آداپتور جداگانه برای تشخیص با داده مشاهده‌شده در بازه‌های کوتاه و وقفه‌دار ساخته شده، نه برای جایگزین کردن موتور اصلی یا اعلام سودآوری.

- فایل CSV باید ستون‌های time,open,high,low,close داشته باشد؛ time برچسب خام ۹۰۰ثانیه‌ای سرور است و به UTC معتبر تبدیل نمی‌شود.
- شکاف‌ها جدا می‌شوند؛ هیچ کندل ساختگی و هیچ عبور معامله از شکاف نداریم.
- سیگنال تنها گذشته بسته‌شده را می‌بیند و ورود در open کندل بعد است.
- قیمت اجرایی ASK برای BUY و ASK خروج SELL با فرض spread جابه‌جا می‌شود؛ commission، slippage و signed swap صریح‌اند.
- اگر swap نامعلوم باشد net سناریویی null می‌شود. برخورد SL و TP در همان کندل با policy پیش‌فرض unknown سود قطعی تولید نمی‌کند. stop_first/target_first نیز فرضی‌اند.
- خروجی همیشه EXPLORATORY_ONLY و market_profitability_verified=false است.
- breakout ده کندل گذشته فقط baseline ثابت و تست فنی است؛ جزو شش candidate اصلی فراز نیست.
- نرم‌افزار هیچ API معاملات، MT5 connection یا نصب ندارد.

## تست
در همین پوشه روی Python 3.10+ این فرمان اجرا شود:

    python -m unittest -v test_historical_diagnostic

در محیط مستقل ChatGPT، ۱۵ تست PASS و صفر FAIL/ERROR ثبت شده‌اند. در نمونه مصنوعی ۴۸ کندلی با دو قطعه، چهار ورود فرضی تولید شده و دو خروجی نامعلوم مانده‌اند. **این آزمایش روی داده واقعی Eplanet نبوده است.**

## اجرای نمونه در ویندوز
فقط پس از بررسی حقوق استفاده و SHA/manifest ورودی خصوصی:

    python historical_diagnostic.py --bars C:\path\to\allowed_sample_m15.csv --output C:\path\to\diagnostic.json --spread 0.3 --slippage 0.1 --commission 0 --swap 0 --policy unknown

تمام هزینه‌های نمونه فرضی‌اند؛ --swap 0 مدرک تاریخیِ صفر بودن سوآپ نیست. با حذف --swap سود خالص null می‌ماند. خروجی خصوصی در GitHub بارگذاری نشود.

## گام بعد Codex Windows
۱. SHA/manifest داده Eplanet موجود را در محیط محلی کنترل و آداپتور را فقط روی فایل‌های مجاز و بدون تغییر raw اجرا کن؛ ۲۶۰ gap و ساعت سرور را حدس نزن.
۲. همان شش candidate موجود در amin_mt5.strategy.plan و candidates را به callback فراخوانی diagnose(...,signal=...,lookback=...) وصل کن. حجم، stop/target، زمان signal و هزینه برای هر candidate باید trace و تست داشته باشند. برای adaptive trailing فعلی از scenario_segment و execution_scenarios موجود reuse کن، نه اینکه آن را بی‌صدا با این baseline جایگزین کنی.
۳. limited_window_gate، ResearchLedger و محدودیت Holdout همچنان لازم‌اند؛ بدون مدارک ساعت/سشن/BidAsk/هزینه فقط تشخیص مشروط و اکتشافی مجاز است.
۴. از یک پنجره کوتاه واقعی و از پیش تعیین‌شده، تعداد سیگنال، موارد بسته/باز و سود/افت سرمایه صرفاً مشروط را گزارش کن. اگر شرایط کافی نیست NO_RESULT بده.
۵. هیچ فایل خام، کلید، داده حساب یا مسیر خصوصی در GitHub نگذار؛ گزارش و تست در Draft PR ثبت شود.

ممنوع: معامله DEMO/REAL، order_send، نصب، تغییر MT5/main، Merge، پرداخت، AWS یا انتشار feed. سایر مأموریت‌ها در صف باقی بمانند.

## محدودیت‌ها
این نسخه هنوز موتور مالی معتبر نیست: سمت ASK داخل کندل فرض مدل است، زمان سرور/سشن و هزینه تاریخی نامعلوم‌اند، قوانین اختصاصی فراز هنوز متصل نیستند و بک‌تست معتبر سالانه مسدود است. هدف این بخش رفع مانع نرم‌افزاری بررسی قطعه‌های کوتاه است، نه اثبات سود.

## پل اتصال شش راهبرد موجود

فایل existing_candidates_bridge.py از amin_mt5.strategy.candidates و scenario_segment.evaluate_segment استفاده می‌کند. با قطعه‌های M15 کوتاه بدون شکاف و در دو سناریوی صریح هزینه، بازپخش *فقط پژوهشی* را ممکن می‌کند؛ نه موتور معاملاتی تازه و نه اثبات سود.

فرمان آزمون همه اجزای این بسته:

    python -m unittest -v test_historical_diagnostic test_existing_candidates_bridge

در محیط جداگانه ChatGPT تعداد ۲۰ تست متمایز PASS شد: ۱۵ تست بازپخش و پنج تست پل با ارزیاب تزریقی. **پل هنوز با سورس اصلی خصوصی Amin-MT5-0.4.1 و داده واقعی Eplanet روی ویندوز اجرا نشده است.** Codex باید این اجرا را انجام دهد و نتیجه فقط با برچسب EXPLORATORY_ONLY و همراه با محدودیت داده، هزینه و Holdout ثبت شود.
