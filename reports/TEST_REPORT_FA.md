# گزارش آزمایش مرحله B — ۴ نوامبر ۲۰۲۶

## نتیجه

ابزار ممیزی مستقل ساخته شد و **۲۸ آزمون کنترل‌شده، بدون شکست، خطا یا skip موفق شدند**. دو اجرای واقعی CLI روی CSV محلی با تنظیمات یکسان، محتوای ممیزی بازتولیدپذیر یکسان تولید کردند. این موفقیت فنی ابزار است؛ اصالت داده، سودآوری یا مجوز تحلیل مالی تأیید نشده است.

| محور | نتیجه |
|---|---|
| ساختار طبق schema صریح | PASS در همین دامنهٔ محدود |
| منشأ، bar timing، timezone، session، سمت قیمت و مجوز داده | هر شش مورد UNVERIFIED |
| مجوز استفادهٔ مالی | NOT_AUTHORIZED؛ مقدار authorized=false |
| SHA-256/اندازهٔ CSV پیش و پس از هر اجرا | یکسان، ۱٬۴۶۱٬۵۴۰ بایت |
| محتوای قابل‌بازتولید دو اجرا | یکسان؛ زمان و مدت اجرا از این امضا کنار گذاشته شده‌اند |
| فایل‌های اصلی تحلیلگر، batch، راهنما، نتیجه قبلی و ZIP | هش‌ها با وضعیت پیش از مرحله B برابر |
| PR مرحله A | Draft، همان commit، بدون تغییر و بدون merge |

## شواهد اجرای واقعی

- Python: 3.12.14؛ ابزار نسخهٔ 1.0.0، فقط کتابخانهٔ استاندارد، بدون نصب یا شبکه در کد ممیزی و تست‌ها.
- فرمان آزمون: `python -B -m unittest discover -s tests -v`؛ لاگ واقعی در [unit-tests.log](unit-tests.log).
- دو فرمان ممیزی و زمان/مدت/هش گزارش‌ها در [verification.json](verification.json) ثبت‌اند. فقط مسیر مطلق ماشین برای جلوگیری از انتشار مسیر خصوصی با placeholder جایگزین شده است؛ فلگ‌ها و فایل‌های پیکربندی همان اجراها هستند.
- گزارش ساختاری اجرای اول، بدون قیمت‌های خام یا مسیر خصوصی، در [data-audit.json](data-audit.json) منتشر می‌شود. فایل واقعی محلی نام `local-audit-run-1.json` دارد؛ بایت‌های گزارش در انتشار تغییر نمی‌کنند. اجرای دوم محلی حفظ شده و امضای آن در verification موجود است؛ گزارش تکراری دوم به مخزن منتقل نمی‌شود.
- هر دو اجرای ممیزی exit code صفر داشتند؛ صفر فقط پایان موفق ممیزی ساختار است. کدهای ۱ و ۲ نیز در آزمون دادهٔ مصنوعی برای ساختار خراب و خطای بحرانی/خطر بازنویسی بررسی شدند.

## مشاهده‌های دادهٔ محلی

- ۲۹٬۲۳۴ رکورد، همه از نظر قواعد اعلام‌شدهٔ ردیفی سازگار؛ ۲۹٬۲۳۴ timestamp یکتا و مرتب؛ صفر رکورد نیازمند قرنطینهٔ ساختاری.
- همهٔ ۲۹٬۲۳۴ رکورد از نظر session نامعلوم‌اند. این دسته با رکوردهای سازگار از نظر ساختار هم‌پوشان است و به تعداد کل اضافه نمی‌شود.
- ۵٬۶۹۴ کندل تخت؛ ۴٬۶۴۸ مورد در یکشنبه بر اساس تفسیر عددی Unix-ms. ۵٬۶۴۰ کندل تخت close برابر close قبلی دارند؛ این به‌تنهایی شاهد پرکردن یا جعل نیست.
- ۵۴ فاصلهٔ بیش از ۱۵ دقیقه؛ بیشترین فاصله ۵۱٫۲۵ ساعت. ۵٬۷۱۰ جایگاه شبکه بین ردیف‌ها مشاهده نشده‌اند؛ این عدد به معنی دادهٔ قطعاً مفقود نیست. علت همهٔ این فاصله‌ها بدون تقویم معتبر UNKNOWN است.
- طولانی‌ترین run تختِ پیوسته از نظر شبکه ۹۲ رکورد است. هیچ flat/gap حذف یا اصلاح نشده است.
- بازه با تفسیر ms: از 2025-11-04 00:00 تا 2026-11-02 23:45 در UTC؛ این تبدیل، گواهی مستقلِ ساعت منبع یا زمان باز/بسته‌شدن کندل نیست.

## آزمون‌های حفاظت و بازتولید

آزمون‌ها با CSVهای کوچک تولیدشدهٔ **مصنوعی** در پوشه‌های موقت اجرا شدند. نمونه‌های مالی واقعی در fixture یا سورس تست قرار ندارند.

- سه نمونهٔ زمان شناخته‌شده، واحد seconds/ns اشتباه، زمان متنی/اعشاری/خارج‌بازه/ناهم‌تراز؛ خطای schema و انواع نامعتبر.
- OHLC ناسازگار، قیمت نامتناهی/غیرعددی، header و encoding خراب، CSV خالی یا ناقص؛ محل خطا و ناقص‌ماندن parsing صریح است.
- تکرار یکسان/متفاوت، ترتیب نزولی و هم‌پوشانی چند خطا در یک رکورد؛ شمارش قرنطینه union است.
- flat/gap بدون حذف خودکار؛ تقویم مصنوعی معلوم در برابر حالت فاقد شواهد؛ نبود مجوز مالی حتی با ادعای VERIFIED در همهٔ ابعاد.
- اختلاف SHA یا اندازه، محدودیت حجم، وجود چند CSV و انتخاب ورودی صریح؛ تغییر آیندهٔ fixture بدون به‌روزرسانی manifest رد می‌شود.
- ورودی/مقصد هم‌پوشان، مقصد داخل پوشهٔ خام، hardlink موجود و رقابت ایجاد فایل؛ هیچ‌کدام overwrite نمی‌شوند.
- تشخیص اختلاف بایت در مرحلهٔ read و تغییر هش پس از ممیزی با شبیه‌سازی کنترل‌شده؛ دادهٔ واقعی برای این تست‌ها تغییر نکرد.
- subprocess واقعی CLI روی fixture مصنوعی، بررسی کد خروجی و گزارش بدون مسیر خصوصی.

## محدودیت و گام بعد

هش قبل/بعد، قفل یا تضمین تشخیص همهٔ تغییرات گذرای نویسندهٔ خارجی نیست. مستندات منشأ/session را این ابزار آفلاین احراز هویت نمی‌کند؛ اظهارات VERIFIED صرفاً به‌عنوان اظهار manifest با این محدودیت نگهداری می‌شوند. فایل‌های داده و تاریخچهٔ دانلود هنوز تأیید نشده‌اند.

هیچ CSV/ZIP/تصویر، فایل محرمانه، راهبرد یا نتیجهٔ مالی به این PR افزوده نشده است. `analyze.py` اصلی و snapshot مرحله A اصلاح نشده‌اند. `run_windows.bat`، downloader، نصب وابستگی، بروکر، معامله، بک‌تست و مراحل C/D اجرا نشده‌اند. Draft PR برای مرور ChatGPT است و بدون تأیید مستقل بعدی merge نمی‌شود.
